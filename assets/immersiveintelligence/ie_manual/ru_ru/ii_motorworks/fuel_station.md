# intro

Заправочная станция — это устройство для автоматической заправки [транспортных средств] поблизости. Для её создания используйте [молот](introduction#introductionHammer) по левому лёгкому инженерному блоку.
# usage
Для работы станции требуется электричество. Заправочная станция заправит любое находящееся поблизости транспортное средство. Количество топлива зависит от типа транспортного средства.
Многие транспортные средства, например [мотоциклы], используют **дизельное топливо**, а [моторные лодки] — **бензин**.
