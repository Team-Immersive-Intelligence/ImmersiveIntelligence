# meta
Производство боеприпасов
Это гильза, а не карандаш!
# bullet
Стрелковое оружие такое же древнее, как и меч. В современной войне для подавления противника может потребоваться значительное количество боеприпасов.
Несмотря на массовое производство, сборка [боеприпасов] по-прежнему является довольно сложным процессом, требующим большого количества этапов.
К счастью, инженерный отдел успешно разработал несколько машин, которые помогают в производственном процессе.
# bullet2
|[item_display]{source:"bullet_twoparts"}|
[Боеприпас] обычно состоит из двух частей: [сердечника](bullet_cores) и [гильзы](#casings). Гильза удерживает всё на месте и [заполнена](#filler) [порохом]. Сердечник вставляется в гильзу.
При желании боеприпасы могут быть заполнены [дополнительными компонентами](bullet_components), которые добавляют улучшенные эффекты.
# casings
Все боеприпасы начинаются с **гильзы**. Большинство гильз могут быть изготовлены с использованием соответствующей формы в [Металлическом прессе](metalPress), но некоторые, такие как [Радиомины](explosives_mines.md#radio_satchel0), требуют ручного изготовления.<br>

# filler
|[multiblock]{mb:"II:Filler"}|
<br>** Наполнитель** - это устройство, используемое для наполнения контейнеров порошками. Наиболее важное применение — наполнение [гильз боеприпасов] [порохом].
# filler_1
Чтобы собрать Наполнитель, используйте [молот](introduction#introductionHammer) по центральному конвейеру. Для его работы требуется энергия. Когда порошок попадает во входное отверстие, он перемещается во внутренний инвентарь. Общее количество порошка/пыли, хранящейся там, указано в mB. Один [порох] равен [100 mB].
# projectile_workshop
@upgradable
|[multiblock]{mb:"II:ProjectileWorkshop"}|
**Мастерская пуль** — это станок, используемый для изготовления или заполнения [сердечников]. Чтобы его собрать, используйте [молот](introduction#introductionHammer) по металлическому ящику слева.
По умолчанию мастерская пуль производит [сердечники из металлических кусочков](bullet_cores).
# projectile_ws_operation
Для работы мастерской требуется энергия. Через интерфейс можно задать [производимый боеприпас] и [тип сердечника]. Это также возможно сделать с помощью [системы данных](data_main.md).
# projectile_workshop1
Сердечник изготавливается в **мастерской пуль** из различных металлических кусочков. Не забывайте использовать [подходящий для работы металл](bullet_cores.md).
Для разных патронов требуются разные сердечники — ПП не может стрелять артиллерийскими снарядами! Разные сердечники могут вмещать разное количество компонентов.
Заполнение [компонентами](bullet_components.md) является [необязательным] и может [повторяться несколько раз] с [теми же или разными компонентами].
# projectile_workshop2
|[upgrade_display]{upgrade:"immersiveintelligence:core_filler"}|
Мастерскую пуль можно модернизировать в [наполнитель боеприпасов]. Это меняет её назначение с производства [сердечников] на заполнение сердечников, произведённых другими мастерскими пуль, с помощью [компонентов пуль](bullet_components.md).
Количество компонентов можно указать с помощью интерфейса или через [систему данных](data_main.md). Максимальное количество зависит от типа сердечника.

# ammunition_assembler
|[multiblock]{mb:"II:AmmunitionAssembler"}|
Завершающим этапом сборки боеприпаса является **Сборщик боеприпасов**.
С помощью этой машины [сердечник] вставляется в [гильзу]. Не забудьте подобрать тип сердечника в соответствии с типом гильзы.
# ammunition_assembler2
Чтобы собрать **Сборщик боеприпасов**, используйте [молот](introduction#introductionHammer) по центральным открытым стальным строительным лесах.
Он также устанавливает предохранитель, определяя, при каких условиях сдетонирует боеприпас. Предохранители можно установить через интерфейс или [пакет данных](data_main.md).
Убедитесь, что гильзы подаются на ближний конвейер, а сердечники — на дальний.
Наконец, боеприпасы можно заправить в [магазины](magazines.md) с помощью [упаковщика](packer.md).
