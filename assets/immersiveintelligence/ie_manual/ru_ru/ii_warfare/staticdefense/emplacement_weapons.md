# intro
По умолчанию на [огневую точку] не установлено вооружение. Вместо этого оружие собирается на огневой точке с помощью [гаечного ключа](electric_tools.md#wrench).
Можно установить несколько видов оружия с многочисленными сильными и слабыми сторонами, чтобы создать невероятно универсальную систему защиты.
# mg0
**Пулемётное гнездо**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/machinegun"}|  
Эта установка является самой простой и *дешёвой* из всех доступных для огневой точки. Это надёжный выбор для борьбы с мягкими наземными целями или лёгкой техникой при использовании [бронебойных винтовочных патронов] в качестве боеприпасов.
# mg00
Обратите внимание, что это оружие не использует [магазины](magazines.md). [Патроны необходимо подавать через вход огневой точки]. Из-за ограниченного вертикального угла стрельбы пулемётное гнездо плохо подходит для стрельбы по воздушным целям.
# mg1
**Пулемётное гнездо** имеет 3 варианта: [Стандартный], [С тяжёлым стволом] и [С водяным охлаждением], которые идентичны вариантам [пехотного пулемёта](machinegun.md).<br>

# chem0
**Тяжёлый жидкомёт**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/heavy_chemthrower"}|
Эта установка предназначена для [ближнего боя] против масс противника. Аналогично обычному [жидкомёту](chemthrower), тяжёлый вариант может быть заправлен различными жидкостями из резервуаров.
**Тяжёлый жидкомёт** имеет [наименьшую дальность] среди всех огневых точек и невероятно плохо подходит для поражения воздушных целей.
# flak0
**Автопушка**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/autocannon"}|
Эта установка — [стандартный, универсальный вариант] для борьбы с мягкими целями, техникой и воздушными целями. В зависимости от боеприпасов она может служить отличным стандартным вариантом для защиты базы от всевозможных угроз.
# flak1
Благодаря высокой скорости поворота и широким диапазонам тангажа и рыскания **автопушка** [особенно эффективна против воздушных целей].
Её недостатки — более низкая скорострельность по сравнению с пулемётом и [относительно небольшой объём магазина](magazines.md), что вынуждает её очень часто перезаряжать. Лучше всего использовать её в сочетании с другими огневыми точками.
# railgun0
**Тяжёлый рельсотрон**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/heavy_railgun"}|
Эта установка используется в [бою на дальних дистанциях, требующем точности]. Она наиболее эффективна против [техники] и [одиночных целей с высокой прочностью]. Урон зависит от металла, из которого изготовлен стержень, или состава [рельсотронной гранаты](grenades.md#1).
# railgun1
Из-за очень низкой скорострельности, скорости поворота и малого инвентаря это плохой выбор для поражения большого количества целей. Для лучшей защиты его необходимо использовать в паре с другими огневыми точками.
К счастью, **тяжёлый рельсотрон** обладает высокой бронепробиваемостью, поэтому лучше всего использовать его против бронированных целей, техники и целей за стальными стенами.
*Нет брони, которую нельзя было бы пробить!*
# cpds0
**Система ПротивоСнарядной Обороны**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/cpds"}|
Вершина компьютерных технологий, механического мастерства и сложного программного обеспечения для наведения — эта огневая точка является злейшим врагом всего, что умеет летать, ходить или плавать. Она использует [винтовочные патроны].
# cpds1
Благодаря поразительной скорострельности, а также быстрому наведению и реагированию, целям практически [невозможно уклониться].
Благодаря усовершенствованной системе наведения это [лучшее оружие для противоснарядной обороны], способное [сбивать артиллерийские снаряды в воздухе]. Для этого его необходимо связать с [радаром](radar.md) или [наблюдателями](#ir_observer0), чтобы максимально увеличить шансы на успешный перехват.
# cpds2
Единственный недостаток — огромное потребление боеприпасов из-за высокой скорострельности. Если у вас возникают проблемы с обеспечением достаточного количества боеприпасов, рассмотрите возможность [ограниченного] использования его в качестве орудия для противоснарядной обороны.
# tesla0
**Башня Теслы**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/tesla"}|
Эта установка — более крупный и усовершенствованный вариант [катушки Теслы](teslaCoil), наносящий [больший урон в расширенном диапазоне]. Это оружие хорошо подходит против [мягких целей], которые оказались слишком близко. Благодаря усовершенствованной системе управления оружие может различать своих и чужих.
# tesla1
Благодаря тому, что она работает на энергии, [ей не нужны боеприпасы] — только постоянный источник электроэнергии. Её недостатки — малая дальность атаки и высокое энергопотребление. Она наиболее эффективна на заболоченных участках, поскольку влажная среда препятствует использованию [антистатической сетки](light_engineer_armor#10), которая полностью её нейтрализует.

# mlrs
**Ракетная установка (РСЗО)**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/rocket_launcher"}|
[Реактивная система залпового огня (РСЗО)], или просто [Ракетная установка], запускает несколько неуправляемых [ракет](bullet_production.md#heavy_ammuniton_assembler) по указанной цели. Ракеты медленны по сравнению с пулями, поэтому для максимальной эффективности по движущимся целям может потребоваться сложное наведение в сочетании с [инфракрасным наблюдателем](#ir_observer0).
# guided_launcher0
**Пусковая установка для ракет с проводным наведением (ПТУР)**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/guided_missile_launcher"}|
Вместо нескольких неуправляемых ракет [Пусковая установка для ракет с проводным наведением] выпускает одну умную ракету, которая управляется в сторону цели. По движущимся целям попасть из неё легче, чем из неуправляемой РСЗО.
# ir_observer0
**Инфракрасный наблюдатель**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/infrared_observer"}|
Эта огневая точка — [устройство наблюдения], используемое для обнаружения врагов на расстоянии и передачи их координат другим огневым точкам. Она считается одним из самых важных, [если не самым важным] вооружением огневых точек.
# ir_observer1
Использование [наблюдателя] может значительно расширить оперативный диапазон других огневых точек. [Наблюдатели] раскрывают и передают координаты позиций противника через [данные](data_main.md) на чрезвычайно больших расстояниях и могут координировать сеть связанных огневых точек для выполнения [точечного прицельного огня по одной цели издалека], повышая общий потенциал системы обороны.
# ir_observer2
Стоит отметить, что [наблюдатель] также может обнаруживать [осветительные снаряды](bullet_components) и передавать их координаты, которые могут быть использованы для точного артиллерийского обстрела.
[Наблюдатели] имеют ограниченное поле зрения в [180 градусов] и не могут развернуться после установки. Это означает, что [один наблюдатель] может охватывать только [одно направление].
# ir_observer2.5
Наблюдатели могут развернуться, когда им будет отправлен соответствующий пакет данных, но учтите, что для этого требуется разборка и скрытие в огневой точке.
# spotlight0
**Прожекторная башня**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/spotlight_tower"}|
Простая огневая точка, [Прожекторная башня] представляет собой укрытую наблюдательную точку со встроенным прожектором, подобным прожектору, который можно использовать для отслеживания врагов в темноте. Направив свет на врага, вы обнаружите его и заставите замереть от страха!
# searchlight0
**Прожектор**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/searchlight"}|
Подобно прожекторной башне, [Прожектор] убирает наблюдательную точку и позволяет установить более крупную световую установку для большего вертикального покрытия, а также повышает точность огня союзников. Лучше всего работает при подключении к [радару](radar.md). Обратите внимание, что горизонтальный радиус действия меньше, чем у башни.
