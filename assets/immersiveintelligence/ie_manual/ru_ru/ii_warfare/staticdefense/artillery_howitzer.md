*Устройство Точечной Бомбардировки*, также известное как **Артиллерийская Установка** — это оружие непрямой наводки, прекрасно подходящее для атаки далеко расположенных целей.
# forming_block
Она собирается использованием [молота инженера](introduction#introductionHammer) по бетону с противоположной стороны от краснокаменного инженерного блока.
# details
**Артиллерийская Установка** состоит из бетонного бункера, [орудийной платформы], [заряжающего механизма], столов управления и [стального люка], который можно открыть, подав [сигнал редстоуна].<br>
[Снаряды](bullet_production.md#bullet) подаются в [нисходящий] конвейер, а отработанные гильзы выбрасываются из [восходящего] конвейера.
Машина требует **большого количества энергии** для работы.
# operation
**Установка** управляется командами с помощью [пакетов данных](data_main#packetsbasics).<br>
|[data_variable]{type:"string", direction:"вход", letter:"c", name:"Приказ", description:"Какое действие выполнит установка", values:[["load","Загружает боеприпасы на платформу"],["unload","Разгружает платформу"],["aim","Наводится на заданные углы, но не стреляет"],["fire","Выстреливает заряженный снаряд под заданным углом"]]}|
Также некоторые команды, вроде [огня] и [наводки], могут требовать дополнительных переменных для их работы; пример пакета может выглядеть так:
|[data_packet]{h:34,data:{c:{Type:"string",Value:"fire"},p:{Type:"float",Value:45},y:{Type:"float",Value:123}}}| 
# loading
Перед выстрелом необходимо снарядить батарею [снарядами](bullet_production.md#bullet). Артиллерийская [платформа] имеет хранилище на 4 снаряда для быстрого доступа во время ведения огня. Чтобы загрузить их, используйте одну из команд [загрузки].<br>
|[data_variable]{type:"string", direction:"вход", letter:"c", name:"Команда загрузки", description:"Какое действие загрузки выполнит установка", values:[["load","Загружает один снаряд"],["load_all","Загружает до 4 снарядов, пока в платформе есть место"],["load1","Загружает снаряд в 1-й слот"],["load2","Загружает снаряд во 2-й слот"],["load3","Загружает снаряд в 3-й слот"],["load4","Загружает снаряд в 4-й слот"]]}|
# unloading
После выстрела пушка выгружает [пустую гильзу] в [хранилище платформы]. Чтобы убрать гильзу или снаряд из хранилища, используйте одну из команд [разгрузки].<br>
|[data_variable]{type:"string", direction:"вход", letter:"c", name:"Команда разгрузки", description:"Какое действие разгрузки выполнит установка", values:[["unload","Разгружает один снаряд"],["unload_all","Полностью опустошает хранилище платформы"],["unload1","Разгружает снаряд из 1-го слота"],["unload2","Разгружает снаряд из 2-го слота"],["unload3","Разгружает снаряд из 3-го слота"],["unload4","Разгружает снаряд из 4-го слота"]]}|
# firing
Для выдачи команды [огня] или [наводки] [пакет данных](data_main#packetsbasics) должен содержать переменные для [вертикального (Тангаж)] и [горизонтального угла (Рысканье)], на которые пушка будет наклонена.
|[data_variable]{type:"float", direction:"вход", letter:"y", name:"Рысканье орудия", description:"Горизонтальный угол ствола орудия", value:"0 to 360"}|
|[data_variable]{type:"float", direction:"вход", letter:"p", name:"Тангаж орудия", description:"Вертикальный угол ствола орудия", value:"0 to -105"}|
# firing1
Вместо прямой передачи угла [баллистический компьютер](ballistic_computer) может использоваться для преобразования [3D-позиции] цели в углы наклона, а [сканирующий конвейер](scanning_conveyor) — для считывания веса [снаряда].
