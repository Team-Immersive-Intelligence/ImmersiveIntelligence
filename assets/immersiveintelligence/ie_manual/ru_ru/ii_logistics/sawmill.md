# meta
Лесопилка
Спиннер, который мы заслужили
# intro
|[multiblock]{mb:"II:Sawmill"}|
Лесопилка представляет собой автоматический столярный станок, работающий на [энергии вращения](rotary_power.md). Она состоит из стола, механического манипулятора и крепления для пилы. Для сборки лесопилки используйте [молот](introduction#introductionHammer) по средним деревянным лесам. 
# saw_blades
|[crafting]{source:"blades"}|
Можно использовать диски из различных материалов. В то же время диск из любого материала равноэффективен при распилке древесины, но диски изготовленные из твердых материалов, таких как [сталь] и [вольфрам], могут резать даже металл.
# slots
Для работы машины требуется постоянная подача энергии вращения. С правой стороны стола подаются брёвна, слева стола выходят доски, опилки сбрасываются под пильным диском.
# recipe_wood

# upgrades
|[upgrade_display]{upgrade:"immersiveintelligence:improved_gearbox"}|
Лесопилку можно улучшить с помощью [Улучшенной коробки передач], чтобы увеличить её рабочую скорость в <config;d;sawmill_gearbox_efficiency> раз. Это также повышает требуемую скорость для работы машины.

|[upgrade_display]{upgrade:"immersiveintelligence:saw_unregulator"}|
Дестабилизирует движение пильного диска, увеличивая количество производимых опилок, хотя при этом часть досок будет потеряна.
