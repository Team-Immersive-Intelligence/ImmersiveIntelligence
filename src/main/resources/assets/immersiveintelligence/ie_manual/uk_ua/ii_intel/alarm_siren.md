# alarm siren 1
Сигнальна сирена - це пристрій, який видає гучний шум при подачі сигналу Redstone (гучність залежить від сили сигналу).
Дріт Redstone можна прикріпити з будь-якого боку. Сирена, як і будь-який конектор редстоуну, може бути переналаштована для використання іншого каналу редстоуна (за замовчуванням білий).
