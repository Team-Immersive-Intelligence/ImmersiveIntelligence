# details
Коли пакет даних отримується на одній зі сторін машини, він обробляється [функціональними схемами](functional_circuits), встановленими в одному з 6 слотів у стійці.
Машина пропускає пакет через усі канали, намагаючись змінити значення його змінних в алфавітному порядку за допомогою [виразів](data_types.md#expression).
[Вираз] **перезапише значення змінної** своїм результатом.
Якщо для змінної немає виразу, вона **проходить без змін**.
# expression
Кожна схема надає власний набір виразів, деякі, як-от [Розширена арифметична схема](functional_circuits#advanced_arithmetic), яка містить усі вирази [Арифметичної схеми](functional_circuits#arithmetic), а також деякі нові.   
Вираз також може мати умовну змінну, [Accessor](data_types.md#accessor) змінної [Логіки](data_types.md#boolean), яка не виконуватиме вираз, якщо значення [TRUE].
# accessor
Машина також пропонує нестандартний тип даних, [Accessor](data_types.md#accessor), який не містить жодних власних значень, але може отримати
останнє значення, призначене змінній з отриманого пакету.

Змінну у виразі можна переключити на [Accessor], натиснувши кнопку «@».
