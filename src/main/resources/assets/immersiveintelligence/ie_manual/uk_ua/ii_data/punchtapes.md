# punchtape_reader2
**Читач перфострічок** має 3 режими реакції на червоний камінь:
[No Redstone] - машина не реагує на сигнали redstone
[Send on Redstone] — машина повторить надсилання останньої прочитаної перфострічки після отримання сигналу Редстоун
[Redstone on Send] - машина випромінює сигнал Redstone, коли отримує пакет
