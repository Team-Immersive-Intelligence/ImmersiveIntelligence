# statements
**Заяви** є будівельними блоками програми **POL**. Кожен **Інструкція** має окреме ім’я, під яким він викликається, і виконує різні дії.
Прикладами дії є встановлення значення змінної, зупинка програми або виконання внутрішньої функції.
Кожна **Інструкція** займає рівно один рядок, але деякі, як-от **Інструкція**, потребують ще одного оператора для належної роботи.
На наступних сторінках перераховано всі **Заяви**, їх використання та приклади використання.
