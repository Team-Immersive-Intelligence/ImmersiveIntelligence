# details
Для роботи **Точному Монтажнику** потрібна [схема складання], [точні інструменти], [інгредієнти для виготовлення] і, звичайно, [електрика].<br>
Машина має один порт для предметів з обох боків.  
[Вхідний порт] *прийматиме лише інгредієнти, позначені поточною встановленою схемою*.  
[Вихідний порт] автоматично виведе на сусідній контейнер.
# schemes
Так само, як [інженер дотримується креслення під час роботи] (blueprints), **Точний монтажник** керується схемою складання.<br><br>
|[crafting]{source:"assembly_scheme"}|
<br>
[Схему] можна встановити через інтерфейс користувача, помістивши її в середній слот.
# tools
Залежно від схеми виробничий процес потребує різних інструментів, ці інструменти з часом виходять із ладу та потребують заміни.
|[crafting]{source:"precision_tools"}|
<br>
Нові інструменти можна вставляти через 3 порти, розташовані на задній панелі.
