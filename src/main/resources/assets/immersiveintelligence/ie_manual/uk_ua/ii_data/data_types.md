# meta
Типи даних
Результати можуть відрізнятися
# strong_typing
[Пакет даних](data_main.md) може містити декілька **Типів** змінних.  
Кожен **Тип** вирізняється [зберіганням] і [представленням] різного роду інформації: наприклад, **Тип числа**, як-от [ціле число](#integer), спеціалізується на зберіганні чисел, і тому математичні вирази з ним можна виконувати набагато простіше, ніж, наприклад, з [рядок](#string) - **Тип тексту**.

Цей спосіб зберігання інформації називається **Стійка типізація** надає кожному **Типу** унікальне призначення.
# default_value
Кожен **Тип** має своє [значення за замовчуванням], яке призначається йому під час ініціалізації.
Якщо [неіснуюча] або [несумісний тип] змінна посилається та [приводиться] до **Типу**, натомість повертається [за замовчуванням] змінна цього **Типу**.
Наприклад, якщо в пакеті:
|[data_packet]{data:{a:{Type:"string",Value:"Hello, World!"}}}|  
'a' - це [Рядок](#string) запитується як [ціле число](#integer), нове [за замовчуванням] (with the type's default value: 0) [ціле число](#integer) буде повернено.
# default_value2
Те саме станеться в такому пакеті:  
|[data_packet]{data:{a:{Type:"string",Value:"123"}}}|
Незважаючи на те, що для людини *текст* "123" здається ідентичним *числу* 123, машина даних сприймає його зовсім інакше. Тип тексту [не можна перетворити] на тип числа, тому він також повертає [ціле число за замовчуванням], або просто кажучи: 0.
# default_value3
Єдиний випадок, коли таке перетворення відбуватиметься належним чином, – це між двома **Сумісними типами** – двома типами, що зберігають подібну інформацію: наприклад, при перетворенні [Float](#float) на [ціле число](#integer)
|[data_packet]{data:{a:{Type:"float",Value:123}}}|  
Цей механізм також є однією з основних концепцій **Стійкого набіру**
# переповнення даних
Кожен **Тип** обмежений числом розміру або довжини.  
Ця функція необхідна, щоб гарантувати відсутність [переповнення даних — ситуації, коли тип займатиме забагато місця та пошкоджуватиме весь пакет.  
Однак це не повністю запобігає [Переповненню даних] — воно все одно може статися, коли забагато [Складених типів] (#types) вкладено один в одного.
Як би в такій ситуації відреагувала машина даних? Він просто не передасть зламаний пакет далі.
# types
Види діляться на дві групи:
**Основні типи** – використовуються для зберігання та представлення [простої], [базової], [форми інформації в однині], наприклад числа або тексту  
Це: [Нічого](#null), [Цілі числа](#integer), [Float](#float), [Логіка](#boolean) та [Рядки](#string).

**Складені типи** – складаються з [кількох] **базових типів** і [об’єднують їх в один об’єкт] для представлення більш складної інформації.
До них належать [ItemStack](#itemstack), [Масив](#array), [FluidStack](#fluidstack), [Вектор](#vector), [Сутності](#entity) і [Мапа](#map).
# null
|[datatype]{type:"%SECTION%",x:52}|
[Нічого] — це спеціальний тип даних, який не має значення.
Це типовий тип змінної [невизначено].
# integer
|[datatype]{type:"%SECTION%",x:52}|
[Ціле число] — це числовий тип даних. Він може зберігати [число] без його дробової складової.
В основному використовується для обчислень і порівнянь чисел.
# float
|[datatype]{type:"%SECTION%",x:52}|
[Float] — це числовий тип даних. Він може зберігати [число] разом із [дробовою складовою].
Використовується для високоточних розрахунків, тобто обчислення кутів дальньої балістичної траєкторії.
# string
|[datatype]{type:"%SECTION%",x:52}|
[Рядок] — це тип даних [тексту], який може містити кілька символів.
Він використовується багатьма пристроями для команд, запитів і повідомлень введення/виведення.
# boolean
|[datatype]{type:"%SECTION%",x:52}|
[Логіка] — це тип [логічних] даних, він може містити одне з двох значень — [True] або [False].
Його основне використання — у логічних функціях за допомогою [логічної алгебри].
# itemstack
|[datatype]{type:"%SECTION%",x:52}|
[ItemStack] — це [складений] тип даних, який містить інформацію про певний [стак] елементів: його [ID], [metadata], [metadata] (damage) і [NBT компонент].
В основному він використовується для встановлення фільтра елементів або позначення певного елемента для машинного завдання.
# fluidstack
|[datatype]{type:"%SECTION%",x:52}|
[FluidStack] — це [складений] тип даних, який містить інформацію про конкретну [рідину] рідини: її [назва], [кількість] і [NBT компонент].
Він в основному використовується для налаштування фільтра рідини або позначення конкретної рідини для завдання машини.
# vector
|[datatype]{type:"%SECTION%",x:52}|
[Вектор] — це [складений] тип даних, що зберігає 3 числових значення. Він може зберігати [цілі числа](#integer), [floats](#float) або [їх суміш].
Він використовується для представлення значень у 3-вимірному просторі, таких як положення або рух об’єктів.
# entity
|[datatype]{type:"%SECTION%",x:52}|
[Сутність] — це [складений] тип даних, який містить інформацію про конкретну [сутність] у світі: її [ім’я], [ID], [позиція], [рух] і [дані NBT].
Здебільшого він використовується у зброї для зберігання та отримання інформації про свої цілі.
# array
|[datatype]{type:"%SECTION%",x:52}|
[Масив] — це [колекція] типів даних, упорядкованих за їх номерами [індекс], починаючи з 0, він може містити будь-який тип даних.
Його часто використовують, коли потрібна більша кількість аргументів, але його потрібно передати як одну змінну.
# map
|[datatype]{type:"%SECTION%",x:52}|
[Карта] — це [колекція] пар із 2 типів даних, які називаються [записи].
Перший елемент запису називається [ключ], а другий — [значення].
Перше можна використовувати для отримання другого і навпаки.
Запис може містити будь-який тип даних як у полі ключа, так і в полі значення.
Його часто використовують для представлення структури з іменованими полями, використовуючи [рядки](#string) як [ключі] та інші типи як [значення].
# expression
|[datatype]{type:"%SECTION%",x:52}|
[Вираз] — це [виконуваний] тип даних, який використовується схемами [Арифметично-логічної машини](arithmetic_logic_machine).
Він виконує попередньо запрограмовану функцію для [вхідних параметрів] у формі значень або їхніх [засобів доступу](#accessor) і повертає значення.
# accessor
|[datatype]{type:"%SECTION%",x:52}|
[Засіб доступу] — це [посилальний] тип даних, який використовується для отримання значення **іншої** змінної в пакеті шляхом посилання на її [букву].
Засоби доступу здебільшого використовуються всередині [виразів](#expression), щоб динамічно отримати значення з **пакету**.
Вони також є невід’ємною частиною [Арифметико-логічної машини](arithmetic_logic_machine).
