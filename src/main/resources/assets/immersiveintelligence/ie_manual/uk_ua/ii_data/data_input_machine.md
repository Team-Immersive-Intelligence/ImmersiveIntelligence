# setup
*Інтерфейс користувача* машини складається з двох розділів.
|[item_display]{source:"punchtape",ornate:true}|
Розділ **Зберігання** використовується для зберігання **пристроїв зберігання даних**, таких як [Перфострічки] і [Схеми пам'яті].
|[item_display]{source:"data_coil",ornate:true}|
Розділ **Дані** використовується для програмування пакета даних, який зберігається машиною.
# editing_packets
**МВД** постійно зберігає один **пакет даних**, який можна легко редагувати через *інтерфейс*.Розділ *Дані* складається зі списку,де за замовчуванням немає змінних.
# editing_variables
Під час редагування змінної ви можете змінити її букву, використовуючи стрілки вгору та вниз, щоб змінити її тип, утримуйте Shift, коли клацаєте її.
# перфострічки
**Машина введення даних** здатна зчитувати **Пакет** із [Написаної перфострічки] і записувати поточний **Пакет** у [Порожній].
Обидві операції можна виконати, вставивши [Перфострічка] у *верхній слот*. Після обробки [Перфострічка] буде виведено в *нижній слот*.
# circuit_interface_upgrade
**Оновлення інтерфейсу схеми** дозволяє **МВД** миттєво зберігати та зчитувати дані в [схемах пам’яті]. Він додає 3 додаткові *слоти* до *інтерфейсу*.
Схеми, вставлені в слот, позначений *червоною крапкою*, будуть записуватися, а ті, що вставлені в слот *зелена крапка*, будуть зчитовані.
Після зчитування схему буде перенесено в *нижній слот*.
