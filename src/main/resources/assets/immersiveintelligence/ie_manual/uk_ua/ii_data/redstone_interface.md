# details
Машина складається з кількох частин, кількох котушок дроту, купи сталевих пластин і кількох електронних трубок,
але ключовими частинами є [порт введення даних], на якому потрібно розмістити [з’єднувач даних](data_wiring.md#connector)
і [вихідний роз’єм redstone] (redstoneWires#1), до якого можна приєднати [провід](wiring#redstoneWires).
# interface
В інтерфейсі користувача є два розділи: дані для редстоуну і навпаки.
Після додавання запису вам потрібно вказати літеру змінної та відповідний колір червоного каменю.
