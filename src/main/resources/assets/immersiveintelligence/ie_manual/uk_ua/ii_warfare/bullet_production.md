# bullet
З новим арсеналом зброї потреба в боєприпасах, щоб нагодувати ворога, стає величезною.
Але збірка куль – це все-таки досить складний процес, який вимагає багатьох етапів.

Куля складається з двох частин: сердечника, снаряда та гільзи для компонента кулі; кожух, корпус
який тримає все на місці і наповнений порохом. Сердечник буде вставлятися в корпус.

# filler
|[multiblock]{mb:"II:Filler"}|

**Наповнювач** – це пристрій для наповнення контейнерів пилом. Найважливішим призначенням є наповнення стріляних гільз порохом.
# filler_1
Для формування наповнювача використовуйте молоток на центральному конвеєрі. Для роботи потрібна енергія. Коли пил поміщається у вхідний отвір, він переміщується в основний резервуар, загальна кількість пилу, що зберігається там, відображається в мB.
# projectile_workshop
@upgradable
|[multiblock]{mb:"II:ProjectileWorkshop"}|
**Майстерня снарядів** – це машина, яка використовується для виготовлення або наповнення [набоїв]. Щоб сформувати його, використовуйте молоток на лівому металевому ящику.
У конфігурації за замовчуванням снарядна майстерня виробляє [набої з металевих самородків](bullet_cores).
# projectile_workshop1
|[item_display]{source:"cores"}|

Для роботи машина потребує енергії. Через його інтерфейс можна встановити вироблені боєприпаси та тип сердечника.
Це також можливо зробити за допомогою системи даних.
# core_component
@upgradable
Майстерню снарядів можна покращити, щоб стати Наповнювачем снарядів. Це змінює роль наповнення [набоїв], виготовлених іншими майстернями снарядів за допомогою <link;bullet_components;§o§nComponents§r;>.

Кількість компонентів можна вказати за допомогою інтерфейсу або через систему даних. Максимальна кількість визначається типом гільзи.
# projectile_workshop2
Сердечник виготовляється в **Снарядній майстерні** з використанням різноманітних самородків металу, наприклад свинцю. Не забувайте використовувати [відповідний метал для роботи](bullet_cores)

Різні раунди вимагають різних ядер. Пістолет-кулемет не може стріляти артилерійськими снарядами, різні сердечники можуть містити різну кількість компонентів.

Заповнення [компонентами] є необов’язковим і може повторюватися кілька разів тими самими або різними компонентами.
# ammunition_assembler
|[multiblock]{mb:"II:AmmunitionAssembler"}|
Завершальним етапом є збірка кулі в **Складальнику боєприпасів**.
У цьому пристрої збірка набою, пам’ятайте, що тип набою відповідає типу корпусу.
# ammunition_assembler2
Щоб сформувати **Складальник Боєприпасів**, використовуйте молоток на центральному сталевому риштуванні, яке відкрито.

Він також встановлює запобіжник, визначаючи, за яких умов його компоненти вибухнуть. Запобіжники можна встановити через інтерфейс або пакет даних. Для роботи машини потрібна електрика.
