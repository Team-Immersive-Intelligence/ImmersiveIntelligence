Ящик для боєприпасів — це переносне сховище для всіх куль. Його можна використовувати для заряджання револьвера, створивши схему заряджання та поклавши всередину патрони.
Щоб відкрити зсув ящика, клацніть правою кнопкою миші порожньою рукою, а потім перезарядіть револьвер або спідзаряд одним клацанням правою кнопкою миші.
# info0
За допомогою гайкового ключа ви можете модифікувати ящик, щоб він відповідав [машині з стрічковою подачею](weapon_upgrades.md#3) або застосувати вставку для способу заряджання турелей за даними.
