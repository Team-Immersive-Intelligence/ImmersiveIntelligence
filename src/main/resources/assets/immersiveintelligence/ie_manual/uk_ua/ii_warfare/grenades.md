# 0
У гірничодобувній промисловості протягом тривалого часу використовували вибухівку, і з шахтарем стався жахливий нещасний випадок, який був неподалік від вибуху.
Вибух від чорного пороху виявився корисним у нову еру війни та конфліктів.

Ручна граната — це метальна зброя, яка містить вибухівку або інший матеріал, який спрацьовує при контакті.
Щоб зібрати його, поєднайте оброблену палицю з відповідним сердечником гранати в [Майстерні боєприпасів](bullet_production#AmmoWorkshop)
# 1
Гранати Рельсової Гармати — боєприпаси для Рельсової Гармати і Важкої Рельсової Гармати, які можна використовувати замість стандартних металевих стрижнів.

Їх можна начинити вибухівкою або осколками, а потім використовувати як переносну артилерійську зброю.
Щоб зібрати його, поєднайте сталевий стрижень із відповідним сердечником гранати в [Майстерні боєприпасів](bullet_production#AmmoWorkshop).
