# intro
С ростом таких объектов, как заводы или электростанции, возрастает потребность в сложной [системе управления].
Поначалу достаточно будет старой доброй проводки из красного камня, но по мере внедрения сложного оборудования начинает проявляться запутанность этой схемы — и это подходящий момент для введения [системы данных].
# packets_basics
**Данные** — это система, основанная на отправке **пакетов** информации через [сеть](data_wiring) подключенных [устройств передачи данных].
В отличие от редстоуна, **пакет данных** — это не постоянный сигнал, а единичное сообщение, отправляемое по мере необходимости и принимаемое сразу после этого.

**Пакет** может хранить до 36 [переменных] различных [типов](data_types.md), предоставляя много места для размещения различной информации.
Каждая [переменная] обозначена одной из 26 букв английского алфавита или цифрой от 0 до 9.
# packets_demo1
Для наглядности рассмотрим пример пакета данных. Такой пакет можно легко создать с помощью [машины ввода данных](data_input_machine.md), а затем отправить в [сеть передачи данных], подключенную к ней.
|[data_packet]{h:32,data:{a:{Type:"string",Value:"Hello, World!"},b:{Type:"boolean",Value:1b},c:{Type:"integer",Value:123}}}|  
Как показано, даже простой **пакет**, подобный приведенному выше примеру, содержит гораздо больше информации, чем может передать за один раз провод красного камня!
# packets_demo2
Переменная 'a' — это [строка](data_types.md#string), содержащая текст ["Hello, World!"]
Переменная 'b' — это [логическое значение](data_types.md#boolean), содержащее значение [True], эквивалентное [сигналу "включено" красного камня]
Переменная 'c' — это [целое число](data_types.md#integer), содержащее значение [123]

Все эти значения были объединены в один **пакет**, что сделало передачу гораздо более [компактной] и [простой], чем если бы она была построена с использованием традиционной схемы на основе красного камня.
# packets_info
Более того, в отличие от редстоуна, данные передаются [без потерь], то есть **пакеты данных** **__не теряют__** никакой информации, независимо от расстояния, которое они преодолевают.
