# meta
Передача данных
Не совсем линии электропередач.
# intro
Данные могут передаваться двумя способами: [проводным] и [беспроводным].
В обоих случаях между отправкой и получением **пакетов данных** нет задержки. Это означает, что вся система постоянно синхронизирована, и __нет случаев, когда пакет мог бы прийти слишком поздно или слишком рано__.
# wired
**Проводная** система передачи данных основана на использовании **коннекторов** - конечных точек, **реле**, позволяющих соединять несколько проводов для формирования и расширения [сети передачи данных] и **устройств передачи данных**, которые отправляют и/или принимают данные.

# data_cable
|[crafting]{source:"%SECTION%"}|
**Кабель данных** — это среда передачи, созданная из множества витых пар медных проводов, покрытых белым изоляционным материалом.
Он обеспечивает быструю, надежную и относительно дальнюю передачу [пакетов данных](data_main.md) без потерь.
# connector
|[crafting]{source:"%SECTION%"}|
**Коннектор данных** служит конечной точкой **сети передачи данных**. Он размещается на боковой стороне **устройства передачи данных**, чтобы позволить ему отправлять и/или принимать **пакеты**.
Подобно своим [электрическим аналогам](wiring), к разъему данных можно подключить только один провод. Для расширения сети используйте [реле данных](#relay).
# connector_colors
В **сети передачи данных** может содержаться несколько **коннекторов** разных цветов, подобно более примитивной системе проводки из красного камня. Когда пакет отправляется через **коннектор**, он будет принят только на **коннекторах** того же цвета.
Использование [молотка инженера] на **коннекторе** изменит его [цвет].
Это позволяет нескольким изолированным **коннекторам** совместно использовать **реле**, [не мешая] друг другу.
# relay
|[crafting]{source:"%SECTION%"}|  
**Реле данных** служит точкой соединения между несколькими [коннекторами](#connector).
Оно не взаимодействует с **устройствами передачи данных**.
# duplex_connector
|[crafting]{source:"%SECTION%"}|
**Дуплексный коннектор** — это разъем для передачи данных с отдельными цветами для [входа] и [выхода].
Он очень полезен в ситуациях, когда **устройство** служит одновременно и входом, и выходом, но имеет только один порт.
Использование [молотка инженера](introduction#introductionHammer) на нем изменит [цвет входа]. Используйте, зажав Shift, чтобы изменить [цвет выхода].
# debugger
|[crafting]{source:"%SECTION%"}|  
**Отладчик данных** — это особый тип [реле данных](#relay), который захватывает, сохраняет и отображает **пакет**, проходящий через него.
Он работает в 3 [режимах], между которыми можно переключаться, используя [молоток](introduction#introductionHammer), при этом по умолчанию используется [режим приемопередатчика].
# debugger2
В режиме [Передатчик] **отладчик** будет передавать тестовый пакет при подаче сигнала красного камня.
|[data_packet]{data:{a:{Type:"string",Value:"Hello, World!"}}}|
<br>В режиме [Приёмник] устройство будет принимать и сохранять любые проходящие через него пакеты данных и при приёме испускать импульс красного камня длительностью [10 тиков].<br>
Режим [Приемопередатчика] комбинирует функции обоих режимов.
# wireless1
**Беспроводная** передача данных — это расширение **проводной** передачи.
Она использует радиосовместимые устройства, такие как [Радиостанция](radio_station), [Радиорюкзак](radio_backpack) и [Радиовзрывчатка](explosives_mines#radio_satchel0).
Для **беспроводной** передачи **пакета** [передатчик] и [приемник] должны использовать одну и ту же [частоту], а [приемник] должен находиться в зоне действия сигнала [передатчика] или [реле].
# wireless2
Любое радиоустройство той же частоты также будет работать как [реле], расширяя вашу беспроводную сеть.
При проектировании радиосетей помните, что каждое устройство имеет [ограниченный максимальный радиус действия передачи], который меняется в зависимости от [погодных условий].
Для получения подробной информации о работе беспроводных сетей воспользуйтесь [радиостанцией](radio_station).
