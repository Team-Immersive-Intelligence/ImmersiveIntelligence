# details
Когда предмет проходит через сканер конвейера, его свойства считываются и немедленно отправляются в виде пакета данных с использованием типа данных **ItemStack**.
Для дальнейшей обработки полученного пакета данных можно использовать [АЛМ](arithmetic_logic_machine.md) с [соответствующей платой](_functional_circuits.md#itemstack) для извлечения необходимой информации из ItemStack.
# uses
**Конвейрный сканер** чаще всего используется как часть счетчика предметов, сортировочной машины или в качестве триггера, активируемого определенным предметом.
Сигнал красного камня выключит его, как и обычный [конвейер](conveyor).
