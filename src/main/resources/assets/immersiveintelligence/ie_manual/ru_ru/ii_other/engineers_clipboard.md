# intro
@level_beginner
По мере роста завода растёт и список задач. [Блокнот инженера] — это полезный инструмент, позволяющий записывать **заметки**, **списки дел** и **копировать настройки** между машинами.<br>
|[crafting]{source:"clipboard"}|<br>
[Блокнот] можно использовать в руке или **разместить** на стене, **присев и щёлкнув ПКМ** по блоку с любой стороны.

# usage
В интерфейсах машин такие компоненты, как **резервуары для жидкостей и пыли**, **выпадающие списки**, **переключатели**, **тумблеры** и **записи переменных данных**, можно копировать и вставлять.
Для этого щёлкните по компоненту интерфейса, чтобы сфокусироваться на нём, затем нажмите [Ctrl+C], после чего откройте **виджет блокнота** или используйте **предмет** в руке, чтобы вставить содержимое.
# usage1
Аналогично записи из [Блокнота] можно вставлять в интерфейсы после фокусировки на элементе и нажатия [Ctrl+V].
