# intro
|[crafting]{source:"co2_filter"}|
Углекислый газ, часто нежелательный побочный продукт сгорания, находит новое применение в процессе [производства резины](rubber_production.md#chemical_steps).
# operation
Фильтр устанавливается по бокам или сверху верхнего блока [улучшенной доменной печи](improvedBlastfurnace) для сбора углерода в процессе выплавки стали.
К фильтру подсоединяется труба для вывода углекислого газа.
