# intro

Мерный стакан — простой, но мощный инструмент для находчивого химика-инженера. Его максимальная вместимость составляет 500 mB, зажав [Shift] и [крутя колёсиком мыши] можно изменять вместимость с шагом в 10 mB. Это позволяет точно брать жидкость из ёмкостей.
