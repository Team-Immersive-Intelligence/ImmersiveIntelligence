# intro
@level_beginner
Завод растёт, как и список задач. Блокнот инженера - полезный инструмент для записи **записей**, **списков дел** и **копирования настроек** между машинами.<br>
|[crafting]{source:"clipboard"}|<br>
[Блокнот] можно использовать в руке или **разместить** на стене **щёлкнув ctrl+ПКМ** по блоку с любой стороны.
# usage
В интерфейсах машин элементы, как **резервуары для жидкостей и пыли**, **выпадающие списки**, **переключатели**, **тумблеры** и **переменные данных**, можно копировать и вставлять.
Для этого щёлкните по элементу интерфейса, чтобы сфокусироваться на нём, затем нажмите [Ctrl+C], после чего откройте **окно блокнота** или используйте **предмет** в руке, чтобы вставить содержимое.
Аналогично записи из [Блокнота] можно вставлять в интерфейсы после фокусировки на элементе и нажатия [Ctrl+V].
