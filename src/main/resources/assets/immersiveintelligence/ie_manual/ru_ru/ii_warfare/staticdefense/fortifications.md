# sandbags
|[crafting]{source:"sandbags"}|
[Мешки с песком] - это недорогая защитная стена, устойчивая к пулям малого калибра и небольшим взрывам.
Они очень полезны при строительстве траншей и используются для создания [огневых точек](emplacement.md).
# sandbags_filler
Отдельные мешки с песком можно создать, наполнив [прочную ткань] [песком] в [Наполнителе](bullet_production#filler_1).
|[machine_recipe]{type:"filler", recipe:"sandbag"}|
В качестве альтернативы можно использовать [гравий] вместо песка.
# hedgehog
|[crafting]{source:"anti_tank_trap"}|
[Противотанковый ёж], также называемый чешским.
 "Ёж" — это пассивное противотранспортное укрепление. Его острые края способны ломать гусеницы и прокалывать шины транспортных средств, а также наносить серьёзный урон лёгкой технике, пытающейся их протаранить.
