# bullet
Стрелковое оружие такое же древнее, как и меч. В современной войне для подавления противника может потребоваться значительное количество боеприпасов.
Несмотря на массовое производство, сборка [боеприпасов] по-прежнему является довольно сложным процессом, требующим большого количества этапов.
К счастью, инженерный отдел успешно разработал несколько машин, которые помогают в производственном процессе.
# bullet2
|[item_display]{source:"bullet_twoparts"}|
[Снаряд] обычно состоит из двух частей: [сердечника](bullet_cores) и [гильзы](#casings). 
Гильза удерживает все на месте и [заполнена](#filler) [порохом]. Сердечник вставляется в гильзу.
При желании сердечник пули может быть заполнен [дополнительными компонентами](bullet_components), которые добавляют разные эффекты.
# casings
Все снаряды начинаются с **гильзы**. Большинство гильз могут быть изготовлены с использованием соответствующей формы в [Металлическом прессе](metalPress), но некоторые, такие как [Радиомины](explosives_mines.md#radio_satchel0), требуют иных оболочек.<br>

# filler
|[multiblock]{mb:"II:Filler"}|
<br>** Наполнитель** - это машина, используемая для наполнения контейнеров порошком. Наиболее важным применением является наполнение [гильз снарядов] [порохом].
# filler_1
Чтобы собрать наполнитель, используйте [молоток](introduction#introductionHammer) на центральном конвейере. Для его работы требуется энергия. Когда пыль попадает во входное отверстие, она перемещается во внутренний инвентарь. Общее количество пыли, хранящейся там, указано в mB. Один [порох] равен [100 mB].
# projectile_workshop
@upgradable
|[multiblock]{mb:"II:ProjectileWorkshop"}|
**Мастерская пуль** - это станок, используемый для изготовления [сердечников]. Чтобы его собрать, используйте [молоток](introduction#introductionHammer) на металлическом ящике слева.
По умолчанию мастерская пуль производит [сердечники из металлических кусочков](bullet_cores).
# projectile_ws_operation
Для работы мастерской требуется энергия. Через интерфейс можно задать [материал] и [тип сердечника]. Это также возможно сделать с помощью [системы данных](data_main.md).
# projectile_workshop1
Сердечник изготавливается в **мастерской пуль** из различных металлических кусочков. Не забывайте использовать [подходящий для работы металл](bullet_cores.md).
Для разных патронов требуются разные сердечники - пистолет-пулемет не может стрелять артиллерийскими снарядами! Разные сердечники могут требовать разное количество материалов на производство.
Заполнение [компонентами](bullet_components.md) является [необязательным] и может [повторяться несколько раз] с [теми же или разными компонентами].
# projectile_workshop2
Мастерскую пуль можно модернизировать в [наполнитель снарядов]. Это изменит его с производства [сердечников] на заполнитель их [компонентами](bullet_components.md).
Количество компонентов можно указать с помощью интерфейса или через [систему данных](data_main.md). Максимальное количество зависит от типа сердечника.

# ammunition_assembler
|[multiblock]{mb:"II:AmmunitionAssembler"}|
Завершающим этапом сборки пули является **Сборщик боеприпасов**.
С помощью этой машины [сердечник] вставляется в [гильзу]. Не забудьте подобрать тип сердечника в соответствии с типом гильзы.
# ammunition_assembler2
Чтобы собрать "Сборщик боеприпасов", используйте [молоток](introduction#introductionHammer) на центральным стальной строительным лесам.
Он также устанавливает предохранитель, определяя, при каких условиях сдетонируют снаряд. Предохранители можно установить через интерфейс или [пакет данных](data_main.md).
Убедитесь, что гильзы подаются на ближний конвейер, а сердечники - на дальний.
Наконец, патроны можно заправить в [магазины](magazines.md) с помощью [упаковщика](packer.md).
