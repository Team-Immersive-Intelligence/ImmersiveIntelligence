# intro
Каждый чанк, станок, транспортное средство и некоторые другие структуры являются [Недвижимостью](ii_warfare/terrain_control/chunks_and_properties.md) и может принадлежать кому-либо.
Право собственности представлено **(Owner Identity)** -  которую также именнуют **Фракцией**.
По умолчанию каждый является *владельцем своих прав собственности*, но можно присоединиться к другой фракции, чтобы разделить право собственности.
