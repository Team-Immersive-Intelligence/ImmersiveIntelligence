# intro
Каждый чанк, мультиблок, транспортное средство и некоторые другие структуры являются [Недвижимостью](ii_warfare/terrain_control/chunks_and_properties.md) и могут принадлежать кому-либо.
Право собственности представлено **Owner Identity**, которую также именуют **Фракцией**.
По умолчанию каждый является *владельцем своей личной идентичности*, но можно присоединиться к другой фракции, чтобы разделить право собственности.
