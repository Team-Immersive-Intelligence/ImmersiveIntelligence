# meta
Флагшток
Встаньте, гимн!
# intro
@hammer;upgradeable;repairable;paintable
|[multiblock]{mb:"II:Flagpole"}|
[Флагшток] - это мультиблок, который позволяет занять близлежащую территорию, держать ее под контролем, а также
вывешивать [свой флаг], чтобы его могли узнать друзья и враги. Чтобы собрать флагшток, используйте [молоток](introduction#introductionHammer) по средним виткам колючей проволоки.
# chunk_loading
Флагшток сохраняет [8 окружающих чанков, загруженных вместе с тем, в который он расположён], и для этого не требуется никаких ресурсов.
Еще одна функция - отображение [флага]. Чтобы разместить флаг, используйте его на одном из деревянных столбов.
Если вы решили сбросить чужой флаг или просто хотите обновить дизайн своего флага, вы можете снять размещенный флаг с помощью [кусачек инженера](wiring#wiringCutters).
# faction)settings
Открыв интерфейс **Флагштока**, вы можете увидеть карту окрестностей.
Другой раздел позволяет вам управлять базовыми настройками вашего [Owner Identity](owner_identity.md).
Этот вид удобен, но очень ограничен по сравнению с тем, который предлагается в [столе стратегического командования](../../ii_intel/strategic_command_table.md).
|[wip_notice]|
# capture_defiance
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/capture_defiance"}|
[Сопротивление захвату] увеличивает минимальное количество вражеских войск поблизости, необходимое для захвата флагштока, с 1 до 3.
# taser_locks
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/taser_locks"}|
[Электрошокер] добавляет к флагштоку [катушку Теслы](TeslaCoil), которая поразит любого врага, который приблизится к ней, нанося урон и оглушая его на короткое время.
# distress_signal
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/distress_signal"}|
[Сигнал бедствия] добавляет [тревожную сирену](../../ii_intel/alarm_siren.md) и небольшую радиоантенну на флагштоке, которые будут оповещать близлежащие дружественные войска о присутствии противника.
# unit_post
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/unit_post"}|
[Гарнизон] позволяет разместить у **флагштока** отряд [солдат], которые будут охранять его и выполнять любое боевое задание, назначенное им в пределах [радиуса действия] Флагштока.
|[wip_notice]|
