# main

[Ящик для боеприпасов] представляет собой переносное хранилище для всех патронов. Его можно использовать для заряжания [револьвера](revolver), создав схему заряжания и поместив [патроны] внутрь.<br>
# info0.0
Чтобы открыть ящик, щелкните по нему Shift + ПКМ пустой рукой, а затем перезарядите [револьвер] или [скоростной загрузчик] щелкнув ПКМ по нему.
