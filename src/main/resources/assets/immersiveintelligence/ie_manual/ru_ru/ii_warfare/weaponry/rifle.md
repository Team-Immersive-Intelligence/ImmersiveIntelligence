# 0
|[item_display]{source:"rifle"}|
Винтовка - лучший друг воюющего инженера. Таких винтовок много, но эта моя.
Винтовка использует [винтовочные патроны]. Стандартная конструкция винтовки имеет встроенный магазин, снаряжаемый [поштучно]. Она поддерживает ограниченный набор [модификаций](#3).
# 1
|[crafting]{source:"rifle"}|
Созданная из простых деталей, [самодельная винтовка] является испытанным оружием, которое побывало во многих сражениях, и, вероятно, первым оружием, с которым столкнется инженер-стрелок.
Из-за своего большого веса имеет [высокое время наизготовки].
# 2
Созданная с высокой точностью, эта [стандартная винтовка] является усовершенствованием по сравнению с ручной версией.
Ее меньшый вес позволяет [сократить время наизготовки].
