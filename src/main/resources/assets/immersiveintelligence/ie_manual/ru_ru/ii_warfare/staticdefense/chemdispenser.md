# 0

Invented by the same engineer who designed the [electric hammer](electric_tools.md#hammer), the Chemical Dispenser was originally for watering crops and stopping fires. However, it also can be used for precisely spraying a position with an [incendiary liquid].
# 1
The [Chemical Dispenser] requires power supplied through a wire to the device's connector and a data signal (or a constant redstone signal) to control it.
