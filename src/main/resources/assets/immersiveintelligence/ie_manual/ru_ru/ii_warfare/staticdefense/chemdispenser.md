# meta
Химический раздатчик
Тёмная ночь, только...
# 0
|[crafting]{source:"chemical_dispenser"}|
Изобретенный тем же инженером, который разработал [электрический молоток](electric_tools.md#hammer), химический раздатчик изначально предназначался для полива сельскохозяйственных культур и тушения пожаров. Однако его также можно использовать для точного опрыскивания местности [зажигательной жидкостью].
# 1
Для управления [химическим раздатчиком] требуется энергия, подводимая по проводу к разъему устройства, и сигнал данных(или постоянный сигнал redstone).
