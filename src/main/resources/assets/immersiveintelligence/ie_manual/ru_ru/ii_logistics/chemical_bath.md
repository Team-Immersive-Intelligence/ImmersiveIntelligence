# details
[Входные] и [выходные порты] для окунаемых предметов расположены спереди.
[Вход для жидкости] и [вход для энергии] расположены сзади.
Когда материалы будут доставлены, машина автоматически запустит производство.
**Внимание** соблюдайте ТБ рядом с бульбулятором ввиду коррозийности многих растворов.
