# intro
|[multiblock]{mb:"II:Sawmill"}|
Лесопилка представляет собой автоматический столярный станок, работающий на [энергии вращенния](rotary_power.md). Она состоит из стола, механического манипулятора и крепления для пилы. Для сборки лесопилки используйте [молоток](введение#introductionHammer) на среднех деревянных лесах. 
# saw_blades
|[crafting]{source:"blades"}|
Можно использовать диски из различных материалов. В то же время диск из любого материала равноэффективен при распилке древесины, но диски изготовленные из твердых материалов, таких как [сталь] и [вольфрам], будут служить дольше.
# slots
Для работы машины требуется постоянная подача энергии вращения. С правой стороны стола подаются брёвна, слева стола выходят доски, опилки сбрасываются под стол.
