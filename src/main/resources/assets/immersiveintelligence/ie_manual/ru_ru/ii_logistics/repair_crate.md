# intro
|[crafting]{source:"repair"}|
Ремонтный ящик - это устройство, используемое для ремонта снаряжения, а в случае модернизации - близлежащих транспортных средств. После установки его необходимо снабдить стальными пластинами для работы.
# details_1
Shift+ + ПКМ откроет или закроет ящик.
Когда он закрыт, можно получить доступ к его инвентарю. Когда он открыт, щелкните ПКМ, чтобы получить эффекты.
В ремонтном ящике будут отремонтированы все предметы, которые хранятся и носятся пользователем.
# details_2
На верхней части ящика можно установить манипулятор. Используйте гаечный ключ на ящике и выберите соответствующую модификацию. После установки к ящику необходимо напрямую подключить электричество. Манипулятор автоматически выполняет ремонт оборудованных элементов и окружающих транспортных средств и блоков.
