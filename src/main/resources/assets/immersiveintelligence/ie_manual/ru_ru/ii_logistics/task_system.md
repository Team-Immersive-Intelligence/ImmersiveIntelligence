# intro
Система задач - это возможность организации работы по расписанию с помощью одной повторяющейся задачи. Задачи используются многими устройствами передачи данных, такими как [манипуляторы](inserters.md), [упаковщики](packer.md) и [маршрутизаторы данных](small_data_devices.md#router). Задачи делятся на две группы:
**Задачи** - задания, которые будут выполняться бесконечно, если их не удалить вручную.
# intro1
**Запросы** - задания, которые являются временными и удаляются сами по себе после завершения (т.е. после того, как пользователь получит определенное количество элементов).
# details
По умолчанию задания выполняются от самого старого к самому новому. Если задание не может быть выполнено, оно будет пропущено. После завершения [задания] (успешно или нет) проверяется, следует ли ее удалять.
# logitags
|[item_display]{source:"logitag_item"}|
**Логистическая метка** или **LogiTags** для краткости, это информационные метки, используемые логистическими машинами II, как [упаковщики](packer.md) и [манипуляторы](inserters.md).
Они содержат информацию о названии груза, его имени, текстовом описании, [личности владельца], пункте отправления, пункте назначения, цветовой метке и номере партии, и могут быть применены к контейнерам, таким как [Ящики](engineers_crates.md), с помощью крафта.
# logitag_printing
Чтобы создать **Логистический манифест**, требуется [Печатный пресс](../ii_data/printing_press.md), загруженный [Пустыми страницами].
Самый простой способ передать информацию о манифесте машине — использовать одну переменную типа [LogiTag](../ii_data/data_types.md#logitag).<br>
|[data_variable]{type:"logitag", direction:"вход", letter:"l", name:"Логистическая метка", description:"Логистическая метка, которая будет напечатана", requirements:{m:"logi_tag"}}|
Поскольку этот тип считается [продвинутым], для него требуется улучшенная [Машина ввода данных](../ii_data/data_input_machine.md).
# logitag_printing2
Альтернативный способ передать информацию о **LogiTag** — использовать [ItemStack](../ii_data/data_types.md#itemstack) существующего предмета «Логистический манифест».<br>
|[data_variable]{type:"itemstack", direction:"вход", letter:"s", name:"Логистическая метка", description:"Логистическая метка, которая будет напечатана", requirements:{m:"logi_tag"}}|
Также можно сделать это с помощью набора переменных пакета:<br><br>
|[data_variable]{type:"string", direction:"вход", letter:"n", name:"Имя", description:"Имя груза"}|
|[data_variable]{type:"string", direction:"вход", letter:"d", name:"Описание", description:"Опциональное более длинное текстовое описание"}|
