# intro
|[multiblock]{mb:"II:Coagulator"}|
Коагулятор — это машина, используемая для обработки [латекса] и создания сырого [каучука] для [дальнейшей обработки](vulcanizer.md). Чтобы собрать, используйте [молот](introduction#introductionHammer) по среднему листовому металлическому блоку на задней части машины.
# usage
[Коагулятор] требует электроэнергию (к массивному коннектору), а также постоянную подачу [латекса] (правый резервуар) и [муравьиной кислоты] (левый резервуар). Стороны меняются местами при переворачивании машины.
|[machine_recipe]{type:"coagulator", recipe:"rubber"}|
# usage2
После смешивания [латекса] с кислотой и образования верхнего «кваркового» слоя, кран поднимет один из ковшей, погружает его в жидкость и возвращается на место, при этом автоматически будет установлен таймер. Через некоторое время [латекс] затвердеет в [сырой каучук], который будет выведен механизмом, удерживающим ковш. Каучук будет сброшен на землю. 
Рекомендуется использовать [конвейерные ленты](conveyor) для сбора.
