# intro

Заправочная станция — это устройство для автоматической заправки [транспортных средств]. Для её создания используйте [молоток](introduction#introductionHammer) на левом лёгком инженерном блоке.
# usage
Для работы станции требуется электропитание. Заправочная станция заправит любое находящееся поблизости транспортное средство. Количество топлива зависит от типа транспортного средства.
Многие транспортные средства, например [мотоциклы], используют **дизельное топливо**, а [моторные лодки] — **бензин**.
