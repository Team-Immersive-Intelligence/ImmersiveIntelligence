# intro
@hammer;level_advanced_industrial
|[multiblock]{mb:"II:ChemicalBath"}|
**化学浸洗槽**是一种由工业级大型浴槽和带有机械爪的移动滑架组成的机器。
|[text]{mb:"II:ChemicalBath"}|
# details
待浸洗物品的[输入]和[输出接口]位于机器正面。
[流体输入]、[能量输入]和[红石控制]位于机器背面。
当物料供应到位后，机器将自动开始生产。
当靠近装有腐蚀性元素的浸洗槽时**务必小心**，因为没有防护栏可以防止你掉入其中。
