# meta
修理箱
螺母与螺栓！
# intro
|[crafting]{source:"repair"}|
修理箱是一种用于修复已装备物品的设备，如果升级后，还可以修复附近的载具。放置后，需要为其提供钢板才能工作。
# details_1
潜行并右键点击可以打开或关闭修理箱。
关闭时，可以访问其物品栏。打开时，右键点击即可获得效果。
修理箱将修复玩家手持和穿戴的所有物品。
# details_2
|[upgrade_display]{upgrade:"immersiveintelligence:inserter"}|
可以在修理箱顶部安装焊接注射器。对关闭的修理箱使用扳手，选择相应的升级即可。安装后，修理箱需要直接连接 MV 或 LV 电力线缆。安装的焊接注射器将自动修复已装备的物品以及周围的载具和方块。
