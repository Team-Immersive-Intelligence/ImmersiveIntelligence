# intro
天空板条箱系统是物品输送的另一种方案。其速度超越任何传送带，且使用绳索使其更廉价、更节省空间。但它也有缺点：需要在两端设置站点，并且根据系统长度需要一定数量的支柱。在长距离运输中，天空板条箱是比传送带更好的选择，不建议在短距离（0-30米）内使用它们。

# skycrate
|[multiblock]{mb:"II:SkycrateStation"}|
天空板条箱站既是输送系统的起点也是终点。要形成该多方块结构，请在中间的脚手架方块上使用[锤子](introduction#introductionHammer)。
要使其运行，需要在其侧面输入旋转动力。
# details_crate
齿轮数量会影响其效率，其原理与[齿轮箱](rotary_power.md#gearboxes)类似。
该站点使用[支架](#frames)将板条箱放入输送系统。支架取自放置在机器后方进给装置后面的[用户提供的板条箱]。运输板条箱通过传送带输入和输出。可以通过施加红石信号强制将板条箱从站点中推出。
# skycart
|[multiblock]{mb:"II:SkycartStation"}|
天空*矿车*站与天空*板条箱*站类似，但使用矿车和铁轨代替板条箱和传送带。要形成该多方块结构，请在中间的脚手架方块上使用[锤子](introduction#introductionHammer)。
# details_cart
与其天空板条箱对应物一样，该站点使用[支架](#frames)将矿车中的物品放入输送系统。矿车只有在铁路道闸升起时才能进入站点。可以通过施加红石信号强制将矿车从站点中推出。在装卸操作完成后，站点会自动弹出矿车。
# skycrate_post
|[multiblock]{mb:"II:SkycratePost"}|
天空板条箱支柱是天空板条箱网络中两点之间的中继点。同一时间只能有两根线缆连接到该支架上。要形成该多方块结构，请在栅栏上使用[锤子](introduction#introductionHammer)。
# minecarts
|[item_display]{source:"minecart_general"}|
板条箱矿车是一种通过铁路运输物品的安全方式。它们可以通过将板条箱放入矿车中来合成。这些板条箱内的物品不会丢失。拆卸时，矿车会分离为矿车和板条箱。
# frames
|[crafting]{source:"mount"}|
天空板条箱支架用于通过滑索运输板条箱。有两种型号：基础型，速度较慢；以及快速电动型，它利用沿途附近的[特斯拉线圈](teslaCoil)提供的能量来快速穿越线路。
