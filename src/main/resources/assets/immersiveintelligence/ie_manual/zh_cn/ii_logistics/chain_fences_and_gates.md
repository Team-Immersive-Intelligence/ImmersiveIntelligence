# fence_blocks
|[crafting]{source:"fence_blocks"}|
铁链围栏可以作为工厂区域之间时尚、工业风格的屏障。它们对于大规模入侵提供的防护能力有限，但足以阻止不受欢迎的访客进入你的基地。有几种不同款式可供选择！
# multiblock_gates
如果标准尺寸的大门对你来说太小了，**工程部**提供适合任何工业或军事设施的大型围栏部署方案。<br>
# upgrades
围栏大门可以进行升级，在顶部添加[刺钢丝]，和/或提供[红石线](redstoneWires)连接，实现远程控制。
