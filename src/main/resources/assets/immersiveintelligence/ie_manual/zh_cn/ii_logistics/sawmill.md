# intro
|[multiblock]{mb:"II:Sawmill"}|
锯木机是一种由[旋转](rotary_power.md)动力驱动的自动木工机械。它由一个工作台、一个机械进给装置和锯片支架组成。要形成该多方块结构，请在中间的木质脚手架方块上使用[锤子](introduction#introductionHammer)。
# saw_blades
|[crafting]{source:"blades"}|
可以安装由不同材料制成的**锯片**。虽然所有锯片都能有效切割木材，但由[钢]和[钨]等硬质材料制成的锯片甚至可以切割金属。
# slots
机器需要从其侧面持续供应[旋转动力](rotary_power.md)。原料可以放入工作台右侧，加工后的物品会输出到地上的木质储物箱中。
# recipe_wood
**锯木机**可用于将各种原木加工成木板，再将木板加工成木棍。

# upgrades
|[upgrade_display]{upgrade:"immersiveintelligence:improved_gearbox"}|
锯木机可以安装[改进型齿轮箱]升级，将其工作速度提高 <config;d;sawmill_gearbox_efficiency> 倍。同时也会提高操作机器所需的转速。

|[upgrade_display]{upgrade:"immersiveintelligence:saw_unregulator"}|
使锯片运动失稳以增加锯末产量，但在此过程中会损失部分木板。
