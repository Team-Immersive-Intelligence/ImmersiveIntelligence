# intro
|[crafting]{source:"medical"}|
医疗箱是一种用于治疗受伤实体的设备。放置后，需要装入基础[再生药水]才能工作。
# details_1
潜行并右键点击可以打开或关闭医疗箱。
关闭时，可以访问其物品栏。打开时，右键点击即可获得效果。在医疗箱的第二个槽位中放入金苹果可启用**钢铁意志**增益效果。该效果可以在射击武器时[提高机动性和专注力]。
# details_2
|[upgrade_display]{upgrade:"immersiveintelligence:inserter"}|
可以在医疗箱顶部安装注射器。对关闭的医疗箱使用扳手，选择相应的升级即可。安装后，医疗箱需要直接连接 MV 或 LV 电力线缆。安装的注射器会自动治疗并给予周围实体增益效果。
