# meta
武器升级
没坏？功能还不够多
# 0
在瞬息万变的冲突中，[多功能性]和[适应性]是最为关键的。铭记这一理念，设计和完善现代军械库的聪明工程师们为武器的改装和个性化留出了空间。需要注意的是，某些改装是**互斥的**。
# 1
|[crafting]{source:"heavy_barrel"}|
[重型枪管]允许[武器](machinegun.md)以[更快的射速]射击，但代价是[精度降低]。
# 2
|[crafting]{source:"water_cooling"}|
[机枪](machinegun.md)的高速射击会导致枪管摩擦生热。热量可能对武器材料造成损害。
为了解决这个问题，可以安装[水冷系统]。在水套内部有一根管子，水在其中冷却枪管。[装瓶机](bottlingMachine)可以重新加注水。
# 3
|[crafting]{source:"belt_fed_loader"}|
[弹链供弹装置]是一种将供弹机构相对于整个[武器](machinegun.md)系统的重量比例最小化的方式，并允许高射速连续射击，无需频繁更换弹匣。

弹药需要由[弹药箱](ammocrate.md#main)提供。
# 4
|[crafting]{source:"second_magazine"}|
[第二弹匣]装置允许[机枪](machinegun.md)装载第二个弹匣，使弹容量翻倍，同时仍保持可移动性。
要装填第二个弹匣，请将其装备到你的[副手]。
# 5
|[crafting]{source:"hasty_bipod"}|
[野战两脚架]是一种轻量级且（说实话）仓促制作的装置。然而，由于设计简单，它易于架设。
这个（几乎无重量的）两脚架的缺点是[后坐力增加]。
# 6
|[crafting]{source:"precise_bipod"}|
[精密两脚架]是野战两脚架的改进版。由更坚固的金属制成，它可以[减少后坐力]，但重量和复杂性的增加会[延长架设时间]。
# 7
|[crafting]{source:"scope"}|
[瞄准镜]是一种提高精度和更好地射击远处目标的简便方法。可安装在多种武器上。
# 8
|[crafting]{source:"ir_scope"}|
[红外瞄准镜]是标准瞄准镜的升级版，还可以使用红外反射器和特殊滤镜提供[夜视]能力。它需要由[电容背包](powerpack)提供能量才能工作。
# 9
|[crafting]{source:"shield"}|
[护盾]是一种为射手提供[额外保护]的简单而有效的方法。
护盾会增加机枪的部署时间。它们可以抵挡有限数量的抛射物，如果[承受过多伤害则会碎裂]。如果未受到伤害，护盾的抵抗力会随时间恢复。
# 10
|[crafting]{source:"tripod"}|
[三脚架]是标准[机枪](machinegun.md)两脚架的替代品。它将水平射击角度增加到[165 度]，并[几乎消除了后坐力]。
它很重且架设缓慢；这使其成为静态防御的理想选择。
# 11
|[crafting]{source:"sturdy_barrel"}|
[坚固枪管]是一种改装，可提高[冲锋枪](submachinegun.md)的[精度]和[弹速]，但会降低[射速]。
# 12
|[crafting]{source:"suppressor"}|
[消音器]使[冲锋枪](submachinegun.md)射击时[几乎无声]，非常适合伏击和渗透行动。它不影响射击速度或穿透力。
# 13
|[crafting]{source:"bottom_loader"}|
[底部装弹器]升级将弹匣装填机构从右侧移至底部，替换了木质前握把。这使得[冲锋枪](submachinegun.md)可以装填直弹匣和弹鼓。
# 14
|[crafting]{source:"folding_stock"}|
[折叠枪托]使[冲锋枪](submachinegun.md)更加[紧凑]，并[缩短了瞄准所需的时间]。非常适合伞兵和特种部队。
# 15
|[crafting]{source:"rifle_grenade_launcher"}|
[步枪榴弹发射器]允许你的[突击步枪](assault_rifle.md)发射[电磁炮榴弹](grenades#1)，尽管射程相比[电磁炮](railgun)显著降低。
# 16
|[crafting]{source:"stereoscopic_rangefinder"}|
[立体测距仪]使用先进的电子电路来计算瞄准方块的的距离，最大距离为[60 米]。它还可以与[无线电标记]配合使用，通过[数据](data_main.md)发送位置。测距仪需要能量才能运行。
# 17
|[crafting]{source:"gyroscopic_stabilizer"}|
[陀螺稳定器]使用先进电路和*物理学(TM)*来大幅减少[突击步枪](assault_rifle.md)的后坐力。[稳定器]需要能量才能运行，每发射一发子弹消耗约 [20 Flux]。
# 18
|[crafting]{source:"electric_firing_motor"}|
[电动击发装置]可在[全自动]模式下提高你的[突击步枪](assault_rifle.md)的射速。[电机]需要能量才能运行，每发射一发子弹消耗约 [10 Flux]。
# 19
|[crafting]{source:"railgun_assisted_chamber"}|
[电磁炮辅助枪膛]可提高[突击步枪](assault_rifle.md)在[手动]模式下发射弹药的初速。[枪膛]需要能量才能运行，每发射一发子弹消耗约 [40 Flux]。
# 20
|[crafting]{source:"sami_automatic"}|
[半自动击发机构]让你告别繁琐的手动装填，并允许你的[步枪](rifle.md)使用[步枪弹匣]。这[提高了武器的射速]。
# 21
|[crafting]{source:"long_barrel"}|
[加长枪管]提高了[步枪](rifle.md)发射弹药的[初速]。然而，它会[降低武器的射速]。
