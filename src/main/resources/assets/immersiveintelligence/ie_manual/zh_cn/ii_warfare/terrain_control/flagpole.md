# meta
旗杆
起立，奏国歌！
# intro
@hammer;upgradeable;repairable;paintable
|[multiblock]{mb:"II:Flagpole"}|
**旗杆**是一种多方块结构，用于标记附近领土、保持区块加载和控制，同时展示[时尚的旗帜]以便友军和敌军识别。要形成该多方块结构，请在中间的刺钢丝方块上使用[锤子](introduction#introductionHammer)。
# chunk_loading
**旗杆**会为其[所有者](owner_identity.md)[认领]并保持[其所在区块及其周围的 8 个区块加载]，且不需要任何资源即可做到这一点。
另一个功能是以[旗帜]形式展示[横幅]。要放置横幅，请在其中一个木质杆块上使用它。
如果要更新你的横幅设计，可以使用[剪线钳](wiring#wiringCutters)移除已放置的旗帜。
# faction)settings
通过打开**旗杆**的界面，你可以查看周围区域的地图，并具备查看功能。
其另一个部分允许你管理[所有者身份](owner_identity.md)的基本设置。
这个视图很方便，但与[战略指挥桌](../../ii_intel/strategic_command_table.md)提供的相比功能非常有限。

# capture_defiance
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/capture_defiance"}|
[抵抗占领]升级将占领**旗杆**所需附近敌军士兵的最低数量从 1 人增加到 3 人，使其更难被夺取。
# taser_locks
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/taser_locks"}|
[特斯拉线圈]升级为**旗杆**增加了一个[特斯拉线圈](teslaCoil)，会对靠近的敌人放电，造成伤害并使其短暂眩晕。
# distress_signal
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/distress_signal"}|
[遇险信号]升级在**旗杆**上安装了一个[警报器](../../ii_intel/alarm_siren.md)和一个小型无线电天线，会在敌人出现时提醒附近的友军，使他们能够更快地响应。
# unit_post
|[upgrade_display]{upgrade:"immersiveintelligence:flagpole/unit_post"}|
[部队哨所]升级允许在**旗杆**处驻扎一队[士兵]，他们会在旗杆的[行动半径]内守卫旗杆并执行指派给他们的任何战斗任务。
