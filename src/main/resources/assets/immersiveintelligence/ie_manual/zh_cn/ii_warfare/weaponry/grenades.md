# 0
长久以来，炸药在许多领域都有应用，从娱乐活动、采矿到战争。
黑火药爆炸的威力即使在新时代的战争与冲突中也被证明是有用的。

[长柄手榴弹]是一种投掷武器，内含炸药或其他接触即触发的材料。
要在[弹药工坊](bullet_production#ammunition_assembler)中组装它，请将[防腐处理木棍]与[相应的榴弹核心]结合。
# 1
[电磁炮榴弹]是用于[电磁炮](railgun)和[重型电磁炮](emplacement_weapons.md#railgun0)的弹药，可以代替标准的金属弹杆使用。
它们可以装填炸药或弹片，然后用作便携式火炮武器。
要在[弹药工坊](bullet_production#ammunition_assembler)中组装它，请将[钢杆]与[相应的榴弹核心]结合。
