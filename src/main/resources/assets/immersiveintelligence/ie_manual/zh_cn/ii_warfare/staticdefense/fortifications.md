# sandbags
|[crafting]{source:"sandbags"}|
[沙袋]是一种廉价的防护墙，能够抵抗小口径子弹和小型爆炸。
它们在构建战壕时非常有用，并且用于制造[炮台工事](emplacement.md)。
# sandbags_filler
单个沙袋可以通过在[填料器](bullet_production#filler_1)中用[沙子]填充[麻布袋]来制作。
|[machine_recipe]{type:"filler", recipe:"sandbag"}|
另外，[砂砾]也可以用作沙子的替代品。
# hedgehog
|[crafting]{source:"anti_tank_trap"}|
[反坦克陷阱]，也称为*反坦克拒马*，是一种被动反载具武器。其锋利的边缘能够切割载具的履带和轮胎，并严重损坏试图撞击它的轻型载具。
