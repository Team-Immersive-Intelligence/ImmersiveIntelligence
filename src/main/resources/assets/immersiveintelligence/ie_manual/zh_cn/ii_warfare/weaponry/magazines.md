# filling
弹匣可以通过两种方式装填。第一种是传统的手动[手工装弹]。只需手持弹匣，然后按住[装填]键。
快捷栏中的子弹将优先装填。当这些子弹用完后，物品栏中的子弹将继续装填弹匣。
<br>要实现工业化并加快装填速度，请考虑使用[打包机](packer.md)。
