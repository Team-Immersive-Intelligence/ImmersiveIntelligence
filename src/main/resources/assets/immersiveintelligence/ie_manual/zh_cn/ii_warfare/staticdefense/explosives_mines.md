# radio_satchel0
当你的行动需要隐秘而精确的方式时，[无线电](radio_station.md)[引爆的炸药包]是正确的选择。无论是采矿作业、建筑拆除，还是破坏铁路桥，炸药包用途广泛，深受战斗工程师和破坏者的喜爱。
# radio_satchel1
|[crafting]{source:"crafting_radio_equipped_satchel"}|
与其他爆炸物外壳不同，[无线电炸药包]需要合成。使用皮革、一个[基础电路](electronic_components.md#basic_general)和铁，破坏行动的典范便诞生了。

# radio_satchel2
引爆爆炸装置的主要方式是使用[无线电信号](radio_station)。为此，必须先使用数据包在[DIM](data_input_machine)中对炸药进行编程。

只有当通过无线电接收到与编程数据包[完全相同]的数据包时，炸药才会引爆。
此外，炸药也可以在完全相同条件下通过[线缆接收数据]，并充当中继器。
# radio_satchel3
炸药也可以使用[红石]引爆。与其他[红石连接器](redstoneWires)类似，它们可以在 16 个通道之一上接收信号。要更改通道，请潜行并对已放置的炸药包使用锤子。

# mines
[地雷]通常用作静态防御措施。其主要用途是阻止敌人进入某个区域，减缓其前进速度，或者（如果他们不够聪明的话）标记他们坟墓的位置。

请记住，地雷不会区分目标。**记录好自己的雷区非常重要**，并使用地图规划而非随机放置。
# landmine0
**地雷**
|[item_display]{source:"landmines"}|
经典、可靠且生产成本低廉：这种类型的地雷是应用最广泛的。其工作原理非常简单：
当[敌人踩上去时]会爆炸，造成严重伤害。但是，掉落的物品和像鸡这样的轻量级生物不会触发引爆。
# landmine1
地雷的一个显著特点是能够将其埋入任何软质方块中，例如其所在位置的泥土、砂砾或粘土。

要将地雷埋入地下，请对其使用[铲子]。虽然任何铲子都可以，但[战壕铲](trench_shovel.md)完成这项工作的速度要快得多。
此外，你可以在地雷上方放置[草]以[完全隐藏它]。
# tripmine
**绊雷**
|[item_display]{source:"tripmine"}|
有时被称为[跳跃地雷]，[绊雷]是一种爆炸装置，不是由重量压力触发，而是由拉动顶部的线触发。
被触发后，地雷会从外壳中跳起并爆炸。要设置它，需要将地雷与另一个地雷或[绊线连接器]连接。
# naval_mine0
**水雷**
|[item_display]{source:"navalmine"}|
水雷是部署在水中的地雷，阻止船只和水生生物到达某个区域，有效击杀接触者。
水雷内部携带更多组件，意味着爆炸威力比地雷更大，在大多数情况下是致命的。
# naval_mine1
要部署**水雷**，首先通过潜行和滚动滚轮设置链条长度。
在水方块上部署水雷；它将部署一个锚车，水雷通过链条连接在锚车上。
矿车会下沉，将水雷一同拉下。水雷将漂浮在海床上方，高度等于锚车上方链条的长度。
# naval_mine2
[水雷需要几秒钟才能进入待发状态]，这意味着你可以安全地部署它们，*不会炸到自己*。
