# intro
|[crafting]{source:"submachinegun"}|
冲锋枪，通常简称为 SMG，是一种专为中近距离交战设计的步兵武器。SMG 可以通过[改装](#2)来提升枪械的某些性能。
# intro2
SMG 的制造成本相对低廉，且生产[冲锋枪弹]也很便宜，因此它是需要[快速机动]和[高射速]的[近距离战斗]的理想选择。<br>
请记住，SMG 会随着与目标距离的增加而[失去精度]。建议在远距离交战时使用[电磁炮](railgun)、[步枪](rifle.md)或[火炮武器](artillery_howitzer.md)。
