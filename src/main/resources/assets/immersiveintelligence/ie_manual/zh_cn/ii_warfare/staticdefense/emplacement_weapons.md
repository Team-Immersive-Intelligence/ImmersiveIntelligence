# meta
炮台武器
武力展示
# intro
[武器站]默认未安装任何武器。相反，需要使用[扳手](electric_tools.md#wrench)在工事上组装武器。
可以安装多种各有优劣的武器，以打造一个极其全面的防御系统。
# mg0
**机枪**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/machinegun"}|
该武器是所有炮台武器中最基础且*最廉价*的。当使用[穿甲机枪弹]作为弹药时，它是应对软性地表目标或轻型载具的可靠选择。
# mg00
请注意，该武器不使用[弹匣](magazines.md)。[必须通过炮台输入口提供散装子弹]。由于其俯仰角有限，机枪炮台不太适合射击空中目标。
# mg1
**机枪**炮台有三种变体：[默认型]、[重型枪管型]和[水冷型]，其功能与[步兵版本](machinegun.md)相同。<br>
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/machinegun/heavy_barrel"}|
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/machinegun/watercooled"}|
# mg2
**机枪**炮台还可以进行[加固]以提高战场生存能力。
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/machinegun/additional_fortifications"}|
# chem0
**重型化学喷射器**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/heavy_chemthrower"}|
该炮台专为[近距离]对抗大量敌人而设计。与普通的[化学喷射器](chemthrower)类似，重型版本可以从流体储罐中填充各种液体。
**重型化学喷射器**炮台在所有炮台中[射程最短]，且对付空中目标的能力极差。
# flak0
**机炮**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/autocannon"}|
该炮台是应对软目标、载具和空中目标的[标准全能型选择]。根据弹药类型的不同，它可以作为基地防御各类威胁的优秀标准选项。
# flak1
由于其高初速以及广泛的俯仰和偏航范围，**机炮**尤其擅长对付[空中目标]。
其缺点是与机枪相比射速较慢，且[弹匣容量相对较小](magazines.md)，导致需要频繁装填。最好与其他炮台配合使用。
# railgun0
**重型电磁炮**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/heavy_railgun"}|
该炮台用于[依赖精度的远程战斗]。最适合对付[载具]和[高耐久度的单一目标]。伤害取决于弹杆所用的金属，或[电磁炮榴弹](grenades.md#1)的构成。
# railgun1
由于其射速极低、旋转速度慢且储物空间小，对付多个目标时效果不佳。需要与其他炮台配合使用以获得更好的防护。
幸运的是，**重型电磁炮**拥有强大的穿甲能力，因此最适合用于对付装甲目标、载具和钢墙后的敌人。
*没有盔甲是坚不可摧的！*
# cpds0
**CPDS**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/cpds"}|
作为计算机技术、机械工艺和精密瞄准软件的巅峰之作，该炮台是所有可飞行、行走或游泳之物的天敌。它使用[机枪弹]。
# cpds1
凭借惊人的射速以及快速跟踪和响应能力，目标几乎[不可能逃脱]。
得益于其先进的瞄准系统，它是[反抛射体防御的最佳武器]，能够[在半空中击落炮弹]。为此，它需要连接到[雷达](radar.md)或[观察者](#ir_observer0)，以最大化成功拦截的几率。
# cpds2
它唯一的缺点是由于射速极高而导致的高昂维护成本。如果你难以提供充足的弹药，可以考虑将其作为应对抛射体的[特殊、最后手段]武器使用。
# tesla0
**特斯拉塔**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/tesla"}|
该炮台是[特斯拉线圈](teslaCoil)更大、更精良的变体，在[更广范围内造成更高伤害]。该武器是应对不慎靠近的[软目标]的良好选择。凭借其先进的控制系统，该武器可以区分敌友。
# tesla1
由于使用电力驱动，[它不需要弹药]——只需要持续供电。其缺点是攻击范围低和能耗高。它在积水区域最为有效，因为潮湿环境会阻止使用[防静电网](light_engineer_armor#10)来完全免疫其伤害。
# mortar
**迫击炮**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/mortar"}|
[迫击炮]炮台是[野战迫击炮](mortar.md)的强化版，提供强大的火炮覆盖，尤其擅长穿透屋顶。
# light_howitzer
**轻型榴弹炮**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/light_howitzer"}|
[轻型榴弹炮]是[火炮榴弹炮](artillery_howitzer.md)的缩小版，提供中程支援，其机动性允许对敌方阵地进行快速而精确的弹幕打击。
# mlrs
**火箭发射器（多管火箭系统）**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/rocket_launcher"}|
[多管火箭发射系统（MLRS）]，或简称为[火箭发射器]，可向指定目标发射多枚非制导[火箭](bullet_production.md#heavy_ammuniton_assembler)。火箭与子弹相比速度较慢，因此若要对付移动目标以达到最大效率，可能需要与[红外观察者](#ir_observer0)配合进行复杂瞄准。
# guided_launcher0
**制导导弹发射器**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/guided_missile_launcher"}|
与发射多枚非制导火箭不同，[制导导弹发射器]发射单枚智能火箭，会向目标方向引导。与非制导的 MLRS 相比，更容易击中移动目标。
# ir_observer0
**红外观察者**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/infrared_observer"}|
该炮台是一种[监视设备]，用于从远处探测敌人并与其他炮台共享其坐标。它被认为是所有炮台武器中最为重要的一种。
# ir_observer1
使用[观察者]可以显著扩展其他炮台的作战范围。[观察者]通过[数据](data_main.md)在极远距离上揭示和传达敌人位置坐标，并可以协调相连炮台网络对远方单一目标执行[精确集中火力打击]，从而提升整个防御系统的潜力。
# ir_observer2
值得注意的是，[观察者]还可以探测到[信号弹](bullet_components)并发送其坐标，这可用于直接制导的精确炮击。
[观察者]的视野范围有限，为[180 度]，一旦设置完毕就无法转向。这意味着[一个观察者]只能覆盖[一个方向]。当发送适当的数据包时，观察者可以转向，但请注意这需要先拆卸并缩回炮台。
# spotlight0
**探照灯塔**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/spotlight_tower"}|
[探照灯塔]是一种质朴的炮台，提供了一个带内置探照灯的掩体观察点，类似于泛光灯，可用于在黑暗中追踪敌人。用灯光照射敌人会暴露其位置并使其因恐惧而冻结！
# searchlight0
**防空探照灯**
|[upgrade_display]{upgrade:"immersiveintelligence:emplacement/searchlight"}|
与探照灯塔类似，[防空探照灯]去除了观察点，允许更大的灯光装置以获得更大的垂直覆盖范围，同时提高友方火力精度。与[雷达](radar.md)连接时效果最佳。请注意，与探照灯塔相比，其水平范围有所减小。
