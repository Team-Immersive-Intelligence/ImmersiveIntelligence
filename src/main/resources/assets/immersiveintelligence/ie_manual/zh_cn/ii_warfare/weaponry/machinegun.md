# 0
|[crafting]{source:"machinegun"}|
机枪是一项开创性的精密新发明，可以有效防御各种威胁。与大多数有人操作武器不同，机枪[无法在移动中射击]。要开火，必须将其放置在空间足够的方块上。
# 1
机枪使用[弹匣](magazines.md)供弹，弹匣可以在[打包机](packer.md)中装填[机枪弹]。射击时，[弹壳]会掉落在地上，可以正常拾取或使用[弹壳袋](casing_pouch.md)收集。机枪容易过热，过热速度取决于射速。与大多数现代设备一样，该枪支持通过[升级](weapon_upgrades)进行不同配置。以下页面提供了[升级汇总](#2)。
