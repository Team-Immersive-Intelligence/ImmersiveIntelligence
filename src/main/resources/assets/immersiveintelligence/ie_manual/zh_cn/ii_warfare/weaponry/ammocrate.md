# main
@upgradable
|[crafting]{source:"ammo_crate"}|
[弹药箱]是一种便携式的子弹存储容器。它可以用于装填[左轮手枪](revolver)，方法是创建一个装填模式并将[子弹]放入其中。
要打开弹药箱，请空手潜行右键点击，然后只需右键点击一次即可重新装填[左轮手枪]或[快速装弹器]。
