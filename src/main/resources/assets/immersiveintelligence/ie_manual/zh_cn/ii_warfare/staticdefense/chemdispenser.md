# 0

化学喷洒器由设计[电动锤](electric_tools.md#hammer)的同一位工程师发明，最初用于浇灌农作物和灭火。然而，它也可以用于精确地向某个位置喷洒[燃烧液体]。
# 1
[化学喷洒器]需要通过线缆向设备的连接器供电，并通过数据信号（或持续的红石信号）进行控制。
