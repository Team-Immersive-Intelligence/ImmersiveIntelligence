# 0
步枪是参战工程师最好的朋友。有很多类似的，但这一把是你的。
步枪使用[机枪弹]。未改装的步枪不使用弹匣，而是[一发一发地装填散装子弹]。它支持有限的[改装](#3)套件。
# 1
|[crafting]{source:"rifle"}|
[手工步枪]由简单的零件制成，是一种久经考验的可靠武器，经历了许多战斗，很可能是射手工程师会操作的第一把武器。
由于重量原因，[准备时间较长]。

|[machine_recipe]{type:"precision_assembler", recipe:"precision_rifle"}|
<br>采用精密工艺制造的[步枪]是对手工版本的改进。
其减轻的重量使得[准备时间更短]。
