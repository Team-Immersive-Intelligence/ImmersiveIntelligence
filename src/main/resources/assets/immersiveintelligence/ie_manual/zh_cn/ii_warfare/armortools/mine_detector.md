# meta
探雷器
不是寻宝游戏！
# 1
|[crafting]{source:"mine_detector"}|
探雷器是一种专门用于探测地雷和隐藏爆炸装置的工具。
它源于一次失败的矿物探测器开发尝试，但最终却成为了军方的救星工具。
# 2
要检查是否有地雷，你需要在[主手]中持有探雷器，并[将其指向一个方块]。地雷的存在会通过“哔”声来指示，距离地雷越近，蜂鸣声的频率越高。<br>
另外值得注意的是，探雷检测并非发生在你的位置，而是在你所注视的方块位置。
# 3
|[item_display]{source:"mine_detector"}|
在成功探测到[地雷或爆炸物](explosives_mines.md)后，可使用[剪线钳](wiring#wiringCutters)或其[电动版本](electric_tools.md#cutter)进行拆除。
拆除后，你就可以安全地破坏该方块了。
