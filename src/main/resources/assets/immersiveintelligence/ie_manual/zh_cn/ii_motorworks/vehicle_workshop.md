# intro
|[施工提示]|
工业进步带来了新的交通工具。车辆工坊使你能够制造这些新载具，最著名的便是[摩托车](motor_bike.md)。要形成该多方块结构，请在左侧的铝制脚手架方块上使用[锤子](introduction#introductionHammer)。
# making_vehicles
该机器需要**石油**、**柴油**或**生物柴油**以及电力才能运行。这些可以通过机器侧面和顶部的相应接口输入。要制造载具，通过界面选择相应的选项，提供所示材料，并确保平台上没有停放的载具。如果所有条件均已满足，点击界面中的条纹按钮，工坊将开始组装你的载具。
# fuel
如果载具使用燃料，它将在中途使用工坊内部储罐进行加注。燃料不会持续很长时间，因此请考虑建造一个[燃料站](fuel_station.md)。
# upgrades
载具也可以进行升级。要应用升级，请将你的载具开到平台上，并通过界面选择有效的升级。安装和移除升级都需要电力和柴油供应。
