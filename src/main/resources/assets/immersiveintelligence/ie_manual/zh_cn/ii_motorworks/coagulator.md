# intro
|[multiblock]{mb:"II:Coagulator"}|
凝固器是一种用于凝固[乳胶]并形成生[橡胶球]以便[进一步加工](vulcanizer.md)的机器。要形成该多方块结构，请在机器背面中央的金属板方块上使用[锤子](introduction#introductionHammer)。
# usage
[凝固器]需要向其重型连接器端口供应电力，并持续供应[乳胶]（右侧储罐）和[甲酸]（左侧储罐）。请注意，如果机器翻转，两侧会互换。
|[machine_recipe]{type:"coagulator", recipe:"rubber"}|
# usage2
当[乳胶]与酸混合并形成上层的“夸克”层后，起重机将拾取其中一个桶，将其浸入，然后放回，同时计时器自动开始计时。一段时间后，[乳胶]将固化为[生橡胶]，并由固定桶的机构输出。橡胶会掉落到地面上。
建议放置[传送带](conveyor)来收集橡胶。
