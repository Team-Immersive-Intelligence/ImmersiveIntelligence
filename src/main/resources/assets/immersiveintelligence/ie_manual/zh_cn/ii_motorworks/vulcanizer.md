# intro

硫化机是[橡胶生产](rubber_production.md)流程中的最后一道工序。要形成该多方块结构，请在靠近储罐的钢制方块上使用[锤子](introduction#introductionHammer)。
# production
通过热量、压力、[模具](#molds)以及一系列添加剂的共同作用，[硫化机]将生橡胶片转化为我们所熟悉的工业橡胶。
橡胶传动带用于制造[更快的传送带](rubber_conveyor_belts)和更高效的[传动皮带](#belts)。
|[machine_recipe]{source:"recipe_belts"}|
# production2

# vulcanizer_compounds
|[crafting]{source:"compound"}|
硫化添加剂由改善橡胶性能的添加物组成。它有两种合成方式：使用两份[焦煤粉]和一份[硅粉]，或使用两份[焦煤粉]与一份[锌粒]和一份[钢粒]。
