橡胶生产
快乐的小树
# rubber_trees
橡胶生产的第一步是在丛林生物群系中找到并收集**橡胶树**的树苗。这些树是[乳胶]的宝贵来源——乳胶是一种白色流体，是工业橡胶的主要成分。
第二步是建立橡胶种植园。当[树苗]长大后，使用[斧头]在[提取孔原木]上刻槽（右键点击）。
# rubber_trees_2
然后，在树旁放置一个[乳胶收集器]，并对收集器使用桶，使其开始收集乳胶。
如果树旁有多个收集器，乳胶将在它们之间分配。当桶装满后，与收集器交互即可将其取出。
# chemical_steps
要开始将乳胶凝固成生橡胶，需要两样东西：**甲酸**和一台[凝固器](coagulator.md)。
要生产甲酸，需要一台[精炼厂](refinery)。将[一氧化碳]与[甲醇]结合即可生成甲酸。
# chemical_steps1
一氧化碳可以通过对二氧化碳进行[电解](electrolyzer.md)来生产，二氧化碳是由[二氧化碳过滤器](carbon_filter.md)收集的污染物和副产品。
甲醇可以通过将镍或铂与氢气混合来生产，氢气通过[电解](electrolyzer.md)水来制取。最后一步是使用[精炼厂](refinery)将两者结合。
# processing
获得乳胶和甲酸后，就可以进行凝固了。使用[凝固器](coagulator.md)制作[生橡胶球]，
然后在[金属冲压机](metalPress)中使用板状模具将其压成片状。最后一步是对生橡胶片进行硫化。使用[硫化机](vulcanizer.md)生产橡胶轮胎或传动皮带。
