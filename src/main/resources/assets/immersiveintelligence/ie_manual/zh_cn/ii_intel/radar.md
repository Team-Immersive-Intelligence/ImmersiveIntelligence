# multiblock and description
@level_circuits,hammer_electric,upgradable
|[multiblock]{mb:"II:Radar"}|
[雷达]是一种大型探测设备，能够在极长距离的直线范围内探测实体。
要形成该多方块结构，请在左侧的木制脚手架方块上使用[电动锤](electric_tools.md)。
# radar 2
雷达有多种用途。它可以与工事武器（如 [CPDS](emplacement_weapons.md#cpds0)）联动，用于远距离拦截弹丸。它也可以与[战略指挥桌](strategic_command_table.md) [（施工中）]联动。雷达运行需要持续供电。
# upgrade
|[upgrade_display]{upgrade:"immersiveintelligence:radio_locators"}|
如果安装了[无线电测向器]升级，雷达还可以探测其范围内的[无线电信号](radio_station.md)并确定其位置。这使得能够对毫无防备的敌人进行精确的炮击伏击。
