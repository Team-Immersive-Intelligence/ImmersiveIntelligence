# meta
双筒望远镜
远处的观察者
# intro
当被观察的目标没有察觉到你的存在时，最能获取到有效信息。目标会表现自然，让你洞悉其行为模式和倾向。
达成这个目的方式有很多，比如渗透和间谍活动……但最安全的选择永远是从远处观察。
# crafting
|[crafting]{source:"binoculars"}|
利用光的折射和透镜的光学原理，远距离观察可以轻松实现。
通过将玻璃精心加工成棱镜和透镜，并将其嵌入金属框架中，即可制作出一副**双筒望远镜**。
# usage
使用**双筒望远镜**时，只需手持该物品并[潜行]即可。得益于光学力学和多透镜的最新研究成果，按需缩放的功能使其成为一款出色的侦察设备。
望远镜内部还安装了一个小型陀螺仪，用于指示你的偏航角度，因为**双筒望远镜**会遮挡你的周边视野。
# infra
|[crafting]{source:"infbinoculars"}|
**红外双筒望远镜**是久经考验的**双筒望远镜**的更先进版本。它采用了尖端光学技术和电子元件，使得在极少光线反射的情况下也能看清事物。<br>
# infra1
凭借**红外双筒望远镜**，隐秘行动的工程师将在夜晚的黑暗帷幕下擅长情报收集工作。
<br>然而，新技术也带来了新的责任。由于夜视设计允许大量光线进入，**红外双筒望远镜** [不应] 在 [明亮区域] 使用。否则可能会导致**暂时性失明**。
# infra2
**红外双筒望远镜**需要能量才能运行。如果未供电，则无法开启红外视觉功能。如果使用者穿戴了[电容背包](powerpack)，则可以在移动中为设备充电。
