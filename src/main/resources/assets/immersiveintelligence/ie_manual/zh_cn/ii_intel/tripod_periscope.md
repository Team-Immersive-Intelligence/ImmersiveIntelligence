# craft and intro
|[crafting]{source:"tripod_periscope"}|
三脚架潜望镜是一种观察设备，由一副双筒望远镜、放大管、旋转机构和三脚架组成。
三脚架潜望镜可以让你从战壕或墙壁后方窥视，而无需冒着被击中的风险。
# tripod periscope 2
与标准的[双筒望远镜](binoculars.md)相比，三脚架潜望镜具有更强大的缩放能力，可以侦察更远的地方，观察极远距离的物体。
<br>三脚架的部署方式与[机枪](machinegun.md)类似，需要你[将物品放置在地面上]，然后[空手与之交互]。
<br>要将其拾起，请[潜行]并与之交互。
