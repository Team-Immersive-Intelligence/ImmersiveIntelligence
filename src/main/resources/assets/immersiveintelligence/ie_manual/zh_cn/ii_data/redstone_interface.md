# details
该机器由多个部分组成，但关键部分是[数据输入端口]（需放置[数据连接器](data_wiring.md#connector)）和[红石输出连接器](redstoneWires#1)（可连接[红石线](wiring#redstoneWires)）。
# interface
在用户界面中有两个部分：数据转红石和红石转数据。
添加条目后，必须指定变量字母及其对应的红石颜色。
你也可以通过[点击右侧的文本]来更改红石转换的解析方式。
要删除某个变量，请[按住 Shift 键并点击它]。
