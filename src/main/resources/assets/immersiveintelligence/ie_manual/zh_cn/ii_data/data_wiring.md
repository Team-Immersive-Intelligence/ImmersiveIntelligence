# meta
数据布线
不完全是电线
# intro
数据传输有两种方式：[有线]和[无线]。
两种方式下，**数据包**的发送和接收之间都没有延迟。这意味着整个系统始终是同步的，**不存在数据包到达过早或过晚的情况**。
# wired
**有线**数据系统依赖于**连接器**——即其端点、**中继器**——用于连接多条线缆以形成和扩展[数据网络]，以及**数据设备**——用于发送和/或接收数据。

# data_cable
|[crafting]{source:"%SECTION%"}|
**数据电缆**是一种传输介质，由多根双绞铜线组成，包裹在白色绝缘材料中。
它能够实现快速、可靠、相对远距离且无损的[数据包](data_main.md)传输。
# connector
|[crafting]{source:"%SECTION%"}|
**数据连接器**用作**数据网络**的端点。它放置在**数据设备**的侧面，以允许其发送和/或接收**数据包**。
与[其电气对应物](wiring)类似，每个数据连接器只能连接一根线缆。要扩展网络，请使用[数据中继器](#relay)。
# connector_colors
**数据网络**可以包含多个不同颜色的**连接器**，类似于更原始的红石线路系统。当数据包通过某个**连接器**发送时，只有相同颜色的**连接器**才能接收到它。
使用[工程师锤]点击**连接器**可以更改其[颜色]。
这允许多个隔离的**连接器**共享**中继器**而[互不干扰]。
# relay
|[crafting]{source:"%SECTION%"}|
**数据中继器**用作多个[连接器](#connector)之间的连接点。
它不与**数据设备**交互。
# duplex_connector
|[crafting]{source:"%SECTION%"}|
**双工连接器**是一种数据连接器，其[输入]和[输出]使用不同的颜色。
在某个**设备**既作为输入又作为输出但只有一个端口的情况下，它非常有用。
使用[工程师锤](introduction#introductionHammer)点击它可以更改[输入颜色]。潜行时使用则可以更改[输出颜色]。
# debugger
|[crafting]{source:"%SECTION%"}|
**数据调试器**是一种特殊类型的[数据中继器](#relay)，可以捕获、存储和显示流经它的**数据包**。
它有三种[模式]，可以通过潜行使用[工程师锤](introduction#introductionHammer)来切换，默认模式为[收发模式]。
# debugger2
在[发送器]模式下，当接收到红石信号时，**调试器**将发送一个测试数据包。
|[data_packet]{data:{a:{Type:"string",Value:"Hello, World!"}}}|
<br>在[接收器]模式下，该设备将接收并存储任何经过它的数据包，并在接收时发出一个[持续 10 tick] 的红石脉冲。<br>
[收发器]模式则结合了以上两种功能。
# wireless1
**无线**数据传输是有线数据传输的扩展。
它使用具有无线电功能的设备，例如[无线电站](radio_station)、[无线电背包](radio_backpack)和[无线电炸药](explosives_mines#radio_satchel0)。
要使**数据包**进行**无线**传输，[发送器]和[接收器]必须使用相同的[频率]，且[接收器]必须在[发送器]或其信号[中继器]的范围内。
# wireless2
任何相同频率的无线电设备也会充当[中继器]，扩展你的无线网络。
在设计无线电网络时，请记住每个设备都有[有限的最大传输范围]，该范围会根据[天气]而变化。
关于无线网络操作的详细信息，请参阅[无线电站](radio_station)。
