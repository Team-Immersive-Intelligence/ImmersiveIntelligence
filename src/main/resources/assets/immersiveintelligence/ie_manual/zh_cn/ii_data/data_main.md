# intro
随着工厂或发电厂这类设施的规模扩大，对复杂[控制系统]的需求也在增加。
起初，可靠的老式红石线路就足够了，但随着复杂机械的部署，红石线路杂乱无章的特性开始显现——而此时便是引入[数据系统]的恰当时机。
# packets_basics
**数据**系统基于通过互联[数据设备]的[网络](data_wiring)发送**信息包**。
与红石不同，**数据包**不是恒定的信号，而是一条独立的消息，在有需求时发送，并在发送后立即被接收。

一个**数据包**最多可以存储 36 个不同[类型](data_types.md)的[变量]，为容纳各种信息提供了充足的空间。
每个[变量]由 26 个字母和数字 0-9 中的一个作为标签。
# packets_demo1
为了更好地说明，我们来看一个示例数据包。这样的数据包可以使用[数据输入机](data_input_machine.md)轻松创建，然后发送到与其连接的[数据网络]。
|[data_packet]{h:32,data:{a:{Type:"string",Value:"Hello, World!"},b:{Type:"boolean",Value:1b},c:{Type:"integer",Value:123}}}|
如上所示，即使是像上面这样的一个简单**数据包**，其所携带的信息也比红石线路一次能传递的信息多得多！
# packets_demo2
变量 'a' 是一个[字符串](data_types.md#string)，包含文本 ["Hello, World!"]
变量 'b' 是一个[布尔值](data_types.md#boolean)，其值为 [True]，相当于红石的["开启"信号]
变量 'c' 是一个[整数](data_types.md#integer)，其值为 [123]

所有这些值都被组合到了单个**数据包**中，使得传输比使用传统红石电路构建更加[紧凑]和[直观]。
# packets_info
此外，与红石不同，数据是[无损]的，这意味着**数据包**无论传输多远都**__不会丢失__**任何信息。
