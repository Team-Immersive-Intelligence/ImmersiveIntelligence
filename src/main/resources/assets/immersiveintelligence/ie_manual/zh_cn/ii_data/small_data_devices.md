# meta
小型数据设备
灰色的未来方块
# combiner
|[crafting]{source:"data_combiner"}|
[数据组合器]是一种可以将来自两侧的两个数据输入合并，并从正面输出的机器。
该机器有一个开关，用于选择优先从哪一侧获取变量。
# combiner2
每个变量还具有侧面覆盖模式。绿色表示优先取左侧，红色表示优先取右侧。较暗的颜色表示如果来自该侧的最新数据包不包含该变量，则移除该变量。
# router
|[crafting]{source:"data_router"}|
[数据路由器]允许将数据包定向到指定的侧面，由整数变量 '0' 定义。
变量 0 接受以下整数值：

底面 - 0，顶面 - 1
北面 - 2，南面 - 3
西面 - 4，东面 - 5
# redstone_buffer
|[crafting]{source:"redstone_buffer"}|
[红石缓冲器]是一种在接收到红石信号时可以暂存传入数据包的设备。关闭红石信号即可释放数据包。
**注意：** 新的数据包到达时会覆盖已暂存的数据包。
# timed_buffer
|[crafting]{source:"timed_buffer"}|
[定时缓冲器]是一种可以将传入数据包暂存指定时间的设备。持续时间由整数变量 '0' 设置，即要等待的 tick 数。
**注意：** 如果缓冲器在倒计时期间接收到新的变量 0，缓冲器计时器将重置。
# small_buffer
|[crafting]{source:"small_data_buffer"}|
[小型数据缓冲器]是一种最多可存储 4 个数据包的设备，在接收到红石信号时可以按先进先出的方式释放它们。
