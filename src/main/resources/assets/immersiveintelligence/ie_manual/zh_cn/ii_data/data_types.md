# meta
数据类型
结果可能有所不同
# strong_typing
[数据包](data_main.md)可以包含多种**类型**的变量。
每种**类型**擅长[存储]和[表示]不同类型的信息。例如，像[整数](#integer)这样的**数字类型**专门用于存储数字，因此对其执行数学运算要比对[字符串](#string)（**文本类型**）执行更加直观。

这种信息存储方式称为**强类型**，赋予每种**类型**独特的用途。
# default_value
每种**类型**都有其[默认值]，在初始化时被赋予。
如果引用了一个[不存在]或[不兼容类型]的变量并将其[转换]为某种**类型**，则会返回该**类型**的[默认值]变量作为替代。
例如，在一个数据包中：
|[data_packet]{data:{a:{Type:"string",Value:"Hello, World!"}}}|
如果请求将 'a'（一个[字符串](#string)）作为[整数](#integer)，则会返回一个新的[默认值]（即该类型的默认值：0）的[整数](#integer)。
# default_value2
同样的情况也会发生在数字以字符串形式存储的数据包中：
|[data_packet]{data:{a:{Type:"string",Value:"123"}}}|
尽管对于人类来说，*文本*“123”看起来与*数字* 123 相同，但数据机看待它们的方式却截然不同。文本类型[无法被当作]数字类型进行评估，因此它同样会返回一个[默认整数]，简单来说就是：0。
# default_value3
唯一能够正确进行评估的情况，是发生在两个**兼容类型**之间——即存储相似类型信息的两种类型，例如将[浮点数](#float)评估为[整数](#integer)时：
|[data_packet]{data:{a:{Type:"float",Value:123}}}|
这种机制也是**强类型**的核心概念之一。
# default_value4
可以使用[算术逻辑机](arithmetic_logic_machine.md)或[大型机计算机]中的[类型转换操作](functions/type_conversion.md)，通过[类型转换电路](functions/_functional_circuits.md)在类型之间进行转换。

# data_overflow
每种**类型**都受大小或长度的限制。
这个特性是为了确保不会发生[数据溢出]——即某个类型占用过多空间导致整个数据包损坏的情况。
但这并不能完全防止[数据溢出]——当过多的[复合类型](#types)相互嵌套时，仍然可能发生。
在这种情况下，数据机会如何反应？它只会简单地不再传递损坏的数据包。
# types
类型分为两组：
**基本类型**——用于存储和表示[简单的]、[基本的]、[单一形式的信息]，例如数字或文本。
包括：[空值](#null)、[整数](#integer)、[浮点数](#float)、[布尔值](#boolean)和[字符串](#string)。

**复合类型**——由[多个]**基本类型**组成，[将它们组合成一个对象]，用于表示更复杂的信息。
包括：[物品堆叠](#itemstack)、[数组](#array)、[流体堆叠](#fluidstack)、[向量](#vector)、[实体](#entity)、[逻辑标签](#logitag)和[映射](#map)。
# null
|[datatype]{type:"%SECTION%",x:52}|
[空值]是一种[特殊]数据类型，它[没有值]。
它是[未定义]变量的默认类型。
# integer
|[datatype]{type:"%SECTION%",x:52}|
[整数]是一种[数字]数据类型。它可以存储不带小数部分的[数字]。
主要用于计算和数字比较。
# float
|[datatype]{type:"%SECTION%",x:52}|
[浮点数]是一种[数字]数据类型。它可以存储带有[小数部分]的[数字]。
用于高精度计算，例如计算远距离弹道轨迹的角度。
# string
|[datatype]{type:"%SECTION%",x:52}|
[字符串]是一种[文本]数据类型，可以包含多个字符。
许多设备将其用于命令、查询和输入/输出消息。
# boolean
|[datatype]{type:"%SECTION%",x:52}|
[布尔值]是一种[逻辑]数据类型，可以保存两个值之一——[真]或[假]。
其主要用途是在使用[布尔代数]的逻辑函数中。
# itemstack
|[datatype]{type:"%SECTION%",x:52}|
[物品堆叠]是一种[复合]数据类型，用于保存特定[堆叠]物品的信息：其[ID]、[数量]、[元数据]（耐久值）和[NBT组件]。
主要用于设置物品过滤器或为机器任务标记特定物品。
# fluidstack
|[datatype]{type:"%SECTION%",x:52}|
[流体堆叠]是一种[复合]数据类型，用于保存特定[流体]的信息：其[名称]、[数量]和[NBT组件]。
主要用于设置流体过滤器或为机器任务标记特定流体。
# vector
|[datatype]{type:"%SECTION%",x:52}|
[向量]是一种[复合]数据类型，存储 3 个数值。它可以存储[整数](#integer)或[浮点数](#float)。
用于表示三维空间中的值，例如物体的位置或运动。
# logitag
|[datatype]{type:"%SECTION%",x:52}|
[逻辑标签]是一种[复合]数据类型，用于存储[物流清单](../ii_logistics/task_system.md#logitags)的信息：其[名称]、[描述]、[所有者身份]、[起点]、[目的地]、[颜色标记]和[批次号]。
用于标识货箱等货物容器。
# entity
|[datatype]{type:"%SECTION%",x:52}|
[实体]是一种[复合]数据类型，用于保存关于世界中特定[实体]的信息：其[名称]、[ID]、[位置]、[运动状态]和[NBT数据]。
主要用于武器系统存储和接收其目标信息。
# array
|[datatype]{type:"%SECTION%",x:52}|
[数组]是一种数据[集合]，其中的元素按其[索引]编号排序（从 0 开始），可以容纳任何数据类型。
通常在需要传递大量参数但必须作为单个变量传递时使用。
# map
|[datatype]{type:"%SECTION%",x:52}|
[映射]是一种由成对的数据类型组成的[集合]，称为[条目]。
条目的第一个元素称为[键]，第二个元素称为[值]。
可以用第一个来获取第二个，反之亦然。
条目的键和值字段都可以持有任何数据类型。
通常用于表示带有命名字段的结构，使用[字符串](#string)作为[键]，其他类型作为[值]。
# expression
|[datatype]{type:"%SECTION%",x:52}|
[表达式]是一种[可执行]数据类型，由[算术逻辑机](arithmetic_logic_machine)的电路使用。
它以值或其[访问器](#accessor)形式的[输入参数]执行预编程函数，并返回一个值。
# accessor
|[datatype]{type:"%SECTION%",x:52}|
[访问器]是一种[引用]数据类型，通过引用其[变量标识符]来获取数据包中**另一个**变量的值。
访问器主要用于[表达式](#expression)内部，以从**数据包**动态获取值。
它们也是[算术逻辑机](arithmetic_logic_machine)不可或缺的组成部分。
