# intro

**精密组装机**是一种高精度制造设备，它按照组装方案中的指令进行操作。
|[text]{mb:"II:PrecisionAssembler"}|
# details
为了正常工作，**精密组装机**需要一份[组装方案]、[精密工具]、[合成原料]，当然还需要[电力]。<br>
该机器的两侧各有一个物品接口。
[输入口] *只接受当前安装的方案所标记的原料*。
[输出口] 会自动将产物输出到相邻的容器中。
# schemes
就像[工程师在工作中遵循蓝图](blueprints)一样，**精密组装机**由组装方案引导。<br>
|[crafting]{source:"assembly_scheme"}| <br>
[方案]可以通过用户界面安装，将其放入中间槽位即可。
# tools
根据方案的不同，制造过程需要不同的工具，这些工具会随着使用而磨损，需要更换。
|[crafting]{source:"precision_tools"}|
