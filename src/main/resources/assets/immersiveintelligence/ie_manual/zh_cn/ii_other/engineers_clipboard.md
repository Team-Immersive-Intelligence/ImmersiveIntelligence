# intro
@初级
随着工厂的发展, 任务清单也在增加. The [工程师剪切板] 是一个实用的工具,允许你记下 **笔记**, **待办事项** 以及在机器之间 **复制设置** .<br>
|[制作]{source:"clipboard"}|<br>
 [工程师剪切板] 可以在手上使用, 或者 **放置** 在墙上通过 *shift右键** 在方块的任意一面.

# usage
在机器界面中, 像 **液体与灰尘罐**, **下拉列表**, **切换按钮**, **开关** and **数据变量条目** 这样的组件可以被复制与粘贴.
要做到这一点, 点击一个页面组件来聚焦它, 然后按 [Ctrl+C], 之后打开 **剪切板工具** 或者使用手上的 **物品** 去复制内容.
同样的, [剪贴板] 的条目也可以在聚焦 GUI 组件后按 [Ctrl+V] 粘贴到gui中.
