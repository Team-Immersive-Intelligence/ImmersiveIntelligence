# intro
|[crafting]{source:"e_hammer"}|
工程师的电动锤是旧式[工程师锤](introduction#introductionHammer)的直接升级版。由于其改进的强度和速度，这把锤子可以建造和构建[高级多方块结构]，例如[无线电站](radio_station.md)。
# wrench
|[crafting]{source:"e_wrench"}|
工程师的电动扳手是工程师扳手的增强版。它安装升级和工事武器的速度比手动扳手快得多。[某些机器无法升级]如果没有[电动扳手]的话。
# cutter
|[crafting]{source:"e_cutter"}|
工程师的电动剪线钳是[工程师剪线钳](wiring#wiringCutters)的改进版本。它可以更快地切断方块（例如[刺钢丝](razorwire)）。
