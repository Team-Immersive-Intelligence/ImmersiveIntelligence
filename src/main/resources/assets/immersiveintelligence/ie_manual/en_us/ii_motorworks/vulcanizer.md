# intro
|[multiblock]{mb:"II:Vulcanizer"}|
The Vulcanizer is the final machine in the [Rubber Production](rubber_production.md) process. To form it use a [Hammer](introduction#introductionHammer) on the steel block nearest to the tank.
# production
Using heat, pressure, [molds](#molds), and set of additional compounds, the [Vulcanizer] transforms raw rubber sheets into a familiar industrial rubber.
Rubber belts are used for creating [faster conveyors](rubber_conveyor_belts) and more efficient [motor belts](#belts).

# production2
Rubber can also be vulcanized and formed into tires, providing the needed suspension for many vehicles.

# molds
To operate the machine, the vulcanizer requires a mold, which determines the final output and electricity usage.
|[crafting]{source:"vulcanizer_blueprint"}|
Vulcanizer molds can be created in the [Engineers Workbench](workbench) using the blueprint above.
# vulcanizer_compounds
|[crafting]{source:"compound"}|
The Vulcanization compound consistof additives which improve rubber's properties. It can be crafted in 2 ways: with two [coke dust] and one [silicon dust], or two [coke dust] with a [zinc grit] and a [steel grit].
