# intro
@level_beginner
As the factory grows, so does the task list. The [Engineer's Clipboard] is a useful tool that allows writing down **notes**, **ToDo lists** and **copying of settings** between machines.<br>
|[crafting]{source:"clipboard"}|<br>
The [Clipboard] can be used in hand, or **placed** on a wall by **shift right-clicking** it on a block from any direction.
# usage
Inside machine interfaces, components such as **Fluid and Dust Tanks**, **Dropdown Lists**, **Toggles**, **Switches** and **Data Variable Entries** can be copied and pasted into.
To do so, click an interface component to focus on it, then press [Ctrl+C], then open the **Clipboard widget** or use the **item** at hand to paste the content.
Similarily, entries from the [Clipboard] can be pasted into GUIs after focusing on the GUI element and pressing [Ctrl+V].
