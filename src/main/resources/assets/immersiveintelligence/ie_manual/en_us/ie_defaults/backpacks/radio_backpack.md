# meta
Radio Backpack
Walkie-Talkie!
# crafting
|[crafting]{source:"backpack"}|
The Radio Backpack relays data packets on its own frequency. It can transmit up to 32 blocks. Use a [Radio Tuner](radio_station) while wearing the backpack to set the frequency. Sneak while using the tuner to read the frequency.
# wearing
Wear the radio in the chest slot or the Baubles body slot. Craft it with a chestplate to attach it to armor. Craft the chestplate alone to remove the radio.
